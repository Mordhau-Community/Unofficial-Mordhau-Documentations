# ما هو جيت؟ {#what-is-git}

يحتفظ Git بسجل للمجلد. في كل مرة تقوم فيها بحفظ نقطة تفتيش - *التزام* - فإنها تسجل ما تغير ومتى ومن فعل ذلك. يمكنك العودة إلى أي نقطة تفتيش سابقة، ويمكن لشخصين العمل على نفس المجلد في الوقت نفسه دون الكتابة فوق بعضهما البعض.

لا علاقة له بـ Mordhau. إنها أداة عامة، تُستخدم تقريبًا في كل مشروع برمجي موجود، ونحن نستخدمها هنا لأن هذه المستندات عبارة عن مجلد من الملفات النصية التي يقوم الكثير من الأشخاص بتحريرها.

::: info
Git و GitHub هما شيئان مختلفان. Git هو البرنامج الموجود على جهاز الكمبيوتر الخاص بك. GitHub هو موقع ويب يقوم بتخزين مستودعات Git عبر الإنترنت. يمكنك استخدام Git بدون GitHub. انظر [ما هو GitHub؟](/ar/contributing/github).
:::

## الكلمات {#the-words}

سوف تصادفك هذه المفردات باستمرار، لذا من المفيد أن تتعرف عليها مبكرًا.

**Repository** (أو الريبو) — مجلد المشروع، بالإضافة إلى سجله بالكامل. هذا الموقع هو مستودع واحد.

**استنساخ** — تنزيل نسخة من المستودع والتاريخ وكل شيء.

**Commit** — نقطة تفتيش محفوظة، مع رسالة تصف ما قمت بتغييره.

**الفرع** — خط عمل منفصل. يمكنك إجراء تغييراتك على الفرع الخاص بك بحيث يستمر الفرع الرئيسي في العمل أثناء وجودك في منتصف الطريق.

**ادفع** — أرسل التزاماتك من جهازك إلى GitHub.

**سحب** — قم بإسقاط الالتزامات التي قام بها أشخاص آخرون.

**دمج** — دمج فرع في آخر.

## الأوامر الخمسة التي تحتاجها بالفعل {#the-five-commands-you-actually-need}

ليس عليك أن تتعلم Git بشكل صحيح للمساهمة هنا. هذه هي الحلقة بأكملها:

```bash
# 1. Get the project onto your machine, once
git clone https://github.com/Mordhau-Community/Unofficial-Mordhau-Documentations.git
cd Unofficial-Mordhau-Documentations

# 2. Start a branch for what you are about to do
git checkout -b fix-rcon-ports

# 3. Edit files in your editor, then check what Git noticed
git status

# 4. Save a checkpoint
git add .
git commit -m "Correct the default RCON port"

# 5. Send it to GitHub
git push origin fix-rcon-ports
```

ثم تفتح طلب سحب على موقع الويب، والذي يتم تغطيته في [ما هو GitHub؟](/ar/contributing/github).

## عادتان تستحقان {#two-habits-worth-having}

**اكتب رسائل التزام تعني شيئًا ما. ** «تم الإصلاح» لا تخبر أحدًا بأي شيء بعد ستة أشهر. "تصحيح منفذ الإشارة في دليل الخادم" يفعل ذلك.

**ابدأ فرعًا جديدًا لكل شيء تعمل عليه. ** إنه يكلف أمرًا واحدًا ويعني أنه يمكنك الحصول على إصلاحين غير مرتبطين أثناء الطيران دون أن يتشابكا معًا.

## إبقاء نسختك محدثة {#keeping-your-copy-current}

إذا قمت بالاستنساخ منذ فترة، فقد قام أشخاص آخرون بتغيير الأمور منذ ذلك الحين. قبل بدء عمل جديد:

```bash
git checkout main
git pull
git checkout -b my-new-branch
```

## إذا واجهتك مشكلة {#if-you-get-stuck}

من المعروف أن رسائل خطأ Git غير مفيدة. لا شيء تفعله محليًا غير قابل للاسترداد طالما أنك لم تقم بحذف المجلد، لذلك لا داعي للذعر.

- [كتاب غيت الرسمي](https://git-scm.com/book/en/v2) - مجاني، ويغطي الفصلان الأولان كل ما سبق بمزيد من التعمق
- [اللعنة، (جيت)!](https://ohshitgit.com/) - إجابات قصيرة على "لقد فعلت شيئًا خاطئًا، كيف يمكنني التراجع عنه"

أو اسأل في [Discord](https://discord.gg/zuX58yRV84). وقد ضرب شخص ما نفس الخطأ.
