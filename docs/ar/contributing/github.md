# ما هو GitHub؟ {#what-is-github}

GitHub هو موقع ويب يستضيف مستودعات Git. يقوم بتخزين المشروع عبر الإنترنت بحيث يعمل الجميع على نفس النسخة، ويضيف الأشياء التي ليس لدى Git نفسه رأي بشأنها: تتبع المشكلات، ومراجعة التعليمات البرمجية، وطلبات السحب.

مصدر هذا الموقع موجود في [Mordhau-Community/Unofficial-Mordhau-Document](https://github.com/Mordhau-Community/Unofficial-Mordhau-Documentations). كل صفحة تقرأها هنا هي ملف Markdown في هذا المستودع.

إذا لم يكن الفرق بين Git وGitHub واضحًا بعد، فاقرأ [ما هو جيت؟](/ar/contributing/git) أولاً.

## الحصول على حساب {#getting-an-account}

مجانا. قم بالتسجيل في [github.com](https://github.com) باستخدام عنوان بريد إلكتروني واسم مستخدم - اسم المستخدم عام ويظهر في كل ما تساهم به، لذا اختر واحدًا يسعدك أن تُعرف به.

قم بتشغيل المصادقة الثنائية أثناء تواجدك في الإعدادات. يتطلب GitHub ذلك للمساهمين على أي حال.

## شوكة، فرع، طلب سحب {#fork-branch-pull-request}

هذا هو سير العمل الذي يعمل عليه الموقع بالكامل، وهو نفسه في كل مكان على GitHub.

### 1. شوكة {#1-fork}

ليس لديك إذن بالدفع مباشرة إلى المستودع الرئيسي، وهذا أمر متعمد. يؤدي النقر فوق **Fork** إلى منحك نسختك الكاملة ضمن حسابك الخاص والتي يمكنك فعل ما تريد به.

### 2. قم بإجراء التغييرات {#2-make-your-changes}

إما في المتصفح، أو عن طريق استنساخ الشوكة الخاصة بك والعمل محليًا. ضعها على فرع بدلاً من وضعها مباشرة على `main`.

### 3. فتح طلب سحب {#3-open-a-pull-request}

طلب السحب هو طلب لسحب التغييرات إلى المستودع الأصلي. GitHubيعرض بالضبط ما قمت بتغييره، سطرًا تلو الآخر، ويمنح الجميع مكانًا لمناقشته قبل دمج أي شيء.

اكتب وصفًا يوضح ما قمت بتغييره ولماذا. إذا تم إصلاح مشكلة، فاذكر رقم المشكلة - كتابة `Fixes #42` تغلق هذه المشكلة تلقائيًا بمجرد دمج طلب السحب.

### 4. الرد على المراجعة {#4-respond-to-review}

سوف يقرأها شخص ما. قد يطلبون التغييرات. ادفع التزامًا آخر إلى نفس الفرع وسيتم تحديث طلب السحب من تلقاء نفسه - ولا تفتح فرعًا جديدًا.

بمجرد الموافقة عليه ودمجه، تقوم Netlify بإعادة بناء الموقع ويصبح التغيير الذي قمت به مباشرًا في غضون بضع دقائق.

## التحرير بدون أي من ذلك {#editing-without-any-of-that}

بالنسبة لخطأ مطبعي، لا تحتاج إلى تفرع أي شيء. تحتوي كل صفحة هنا على رابط **تعديل هذه الصفحة** في الأسفل. فهو يفتح محرر GitHub على هذا الملف بالضبط، وعندما تقوم بالحفظ، يقوم GitHub بصمت بإجراء الشوكة وطلب السحب نيابةً عنك.

## المشكلات {#issues}

[متتبع القضايا](https://github.com/Mordhau-Community/Unofficial-Mordhau-Documentations/issues) هو المكان الذي يتم فيه الإبلاغ عن المشكلات وتخطيط العمل. افتح واحدة إذا وجدت شيئًا خاطئًا ولن تقوم بإصلاحه بنفسك، أو إذا كنت تريد اقتراح صفحة غير موجودة، أو إذا لم تكن متأكدًا مما إذا كانت الفكرة تستحق التنفيذ قبل قضاء الوقت فيها.

ابحث في المشكلات الموجودة أولاً. ربما قام شخص ما برفعه بالفعل.

## مراقبة المستودع {#watching-the-repository}

سيرسل لك الزر **مراقبة** الموجود أعلى المستودع بريدًا إلكترونيًا عند حدوث أشياء. **مخصص → المشكلات** عادةً ما يكون الإعداد الصحيح إذا كنت تريد المساعدة ولكنك لا تريد الحصول على إشعار لكل التزام.

## تعلم المزيد {#learning-more}

GitHub [أسرع](https://docs.github.com/en/get-started/quickstart) جيد حقًا ويستغرق حوالي خمسة عشر دقيقة. تحتوي GitHub Skills أيضًا على دورة [Introduction to GitHub](https://github.com/skills/introduction-to-github) المجانية التي ترشدك خلال فتح طلب سحب حقيقي.
