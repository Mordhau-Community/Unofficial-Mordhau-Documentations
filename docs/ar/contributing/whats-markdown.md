# ما هي Markdown {#what-is-markdown}

Markdown هي لغة ترميزية خفيفة الوزن تستخدم لتنسيق النص بطريقة بسيطة وفعالة. تم إنشاؤه في عام 2004 بواسطة جون جروبر وآرون سوارتز، بهدف جعل المستندات النصية العادية جذابة بصريًا وقابلة للتحويل بسهولة إلى تنسيقات منظمة مثل HTML. يستخدم Markdown على نطاق واسع في التوثيق والمدونات ورسائل البريد الإلكتروني ومستودعات التعليمات البرمجية مثل GitHub.

ليس لهذه اللغة الترميزية أي صلة باللعبة Mordhau أو تطويرها أو إنشاء تعديلات لها. إنه ببساطة مجال من المعرفة موجود بشكل مستقل وله استخدامات متعددة عبر مجالات مختلفة. نحن نشرح ذلك هنا فقط لأننا نستخدمه للمساهمة في توثيق اللعبة Mordhau، التي تقرأ من خلالها هذه الصفحة.

::: info
**معلومات لأولئك الذين ليسوا على دراية بالبرمجة أو مواقع الويب:**
<br>
HTML هي أيضًا لغة ترميزية وهي البنية الأساسية لـجميع المواقع. في هذه الصفحة، ليس مطلوبًا منك تعلمها أو فهمها إذا كانت نيتك هي المساهمة فقط في وثائق Mordhau. تحتاج ببساطة إلى تعلم Markdown، والذي يتم تحويله في النهاية إلى كود HTML.
<br><br>

## أين يتم استخدام Markdown؟ {#where-is-markdown-used}

يتم استخدام Markdown في سياقات مختلفة نظرًا لبساطته وتعدد استخداماته. فيما يلي بعض المجالات الشائعة التي يتم فيها تطبيق Markdown:

1. **الوثائق الفنية: **<br> يستخدم Markdown على نطاق واسع لكتابة ملفات README في مستودعات مثل GitHub وGitLab وبيتبوكيت.
2. ** منصات التدوين: ** <br> تدعم العديد من المنصات، مثل Medium أو Jekyll، Markdown لإنشاء منشورات جيدة التنسيق بسهولة.
3. **أنظمة إدارة المحتوى (CMS):** <br> غالبًا ما يُستخدم Markdown في مولدات المواقع الثابتة مثل Hugo وGatsby.
4. ** البريد الإلكتروني والمراسلة: ** <br> يساعد Markdown في تنسيق رسائل البريد الإلكتروني أو رسائل الدردشة النظيفة والمهنية، خاصة في أدوات مثل Slack أو Discord.
5. ** تطبيقات تدوين الملاحظات: ** <br> تدعم الأدوات الشائعة مثل Notion وObsidian وEvernote Markdown لتنظيم الملاحظات بكفاءة.
6. **المنصات التعليمية:** <br> يتم استخدام Markdown في مواقع الويكي والبرامج التعليمية لتقديم معلومات نظيفة ومنظمة.

## كيف يعمل Markdown؟ {#how-does-markdown-work}

يستخدم Markdown بناء جملة نص عادي بأحرف خاصة لتعريف التنسيق. فيما يلي بعض الأمثلة:

### 1- العناوين: {#1-headings}

```md
# Heading 1

## Heading 2

### Heading 3
```

العنوان عبارة عن سطر يبدأ بالرقم واحد إلى ستةأحرف `#`. واحد `#` هو عنوان الصفحة، `##` هو قسم، `###` هو قسم فرعي. اترك سطرًا فارغًا بعد ذلك.

### 2- التركيز: {#2-emphasis}

```md
*italic* or _italic_
**bold** or __bold__
***bold italic***
~~struck through~~
```

### 3- القوائم: {#3-lists}

```md
- first item
- second item
  - a nested item, indented by two spaces

1. numbered
2. list
3. of things
```

القوائم المرقمة تعيد ترقيم نفسها، حتى تتمكن من الكتابة`1.` في كل سطر وسيستمر حساب Markdown بشكل صحيح.

### 4- الروابط: {#4-links}

```md
[text people click](https://example.com)
```

### 5- الصور: {#5-images}

```md
![description of the image](/path/to/image.webp)
```

الوصف الموجود بين قوسين مربعين هو ما يعلنه قارئو الشاشة وما يظهر إذا فشل تحميل الصورة، لذا اكتب شيئًا حقيقيًا هناك.

### 6- الكود: {#6-code}

لف بضع كلمات في علامات خلفية واحدة لتمييزها كرمز - مفيد لأسماء الملفات والأوامر ومفاتيح التكوين. لأي شيء أطول، استخدم ثلاث علامات خلفية وقم بتسمية اللغة:

````md
```bash
العقدة -v
```
````

### 7- الاقتباسات: {#7-quotes}

```md
> Anything after a > is a quote block.
```

### 8- الجداول: {#8-tables}

```md
| Setting | Meaning |
| --- | --- |
| MaxSlots | How many players fit on the server |
| ServerName | The name shown in the browser |
```

الشرطات الموجودة في السطر الثاني هي التي تحوله إلى جدول. ليس من الضروري أن تصطف الأعمدة في المصدر.

## ما لا يفعله Markdown {#what-markdown-does-not-do}

Markdown لا يحتوي عمدًا على تركيب جملة للألوان أو الخطوط أو محاذاة النص أو التخطيط. هذا هو المغزى من الأمر - تصف الوثيقة هيكلها، ويقرر الموقع كيف تبدو البنية. إذا وجدت نفسك تقاوم هذا الأمر، فعادةً ما تحاول القيام بشيء يجب أن يتعامل معه الموضوع بدلاً من ذلك.
