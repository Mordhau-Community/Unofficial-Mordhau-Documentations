# الأدوات المطلوبة {#required-tools}

لا تحتاج إلى الكثير للعمل على هذه المستندات. كل شيء مدرج هنا مجاني ويعمل على Windows وmacOS وLinux.

## Node.js {#nodejs}

VitePress يعمل على Node، لذلك هذا ليس اختياريًا. قم بتنزيل الإصدار **LTS** من [nodejs.org](https://nodejs.org/en) — أي شيء بدءًا من Node 18 فما فوق يعمل.

بمجرد الانتهاء من التثبيت، افتح الوحدة الطرفية وتحقق منها:

```bash
node -v
npm -v
```

إذا قام كلاهما بطباعة رقم الإصدار، فأنت جيد. إذا أخبرتك الوحدة الطرفية بأن الأمر لم يتم العثور عليه، فأغلقه وافتح واحدًا جديدًا. يضيف المثبت Node إلى PATH الخاص بك فقط للمحطات الطرفية المفتوحة بعد تشغيله.

## Git {#git}

Git هو ما تستخدمه لتنزيل المستودع وإرسال التغييرات مرة أخرى. احصل عليه من [git-scm.com](https://git-scm.com/downloads).

عند التثبيت الجديد، يجب أن تخبر Git من أنت، وإلا فلن يكون لالتزاماتك أي مؤلف:

```bash
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
```

استخدم نفس عنوان البريد الإلكتروني الخاص بكلن يقوم حساب GitHub أو GitHub بربط الالتزامات بملفك الشخصي.

## Visual Studio Code {#visual-studio-code}

أي محرر نصوص سيفي بالغرض، ولكن تم إعداد المستودع لـ [VS Code](https://code.visualstudio.com/) ويفترض باقي هذا الدليل أنك تستخدمه.

عند فتح مجلد المشروع للمرة الأولى، سيعرض VS Code إشعارًا يسألك عما إذا كنت تريد تثبيت الملحقات الموصى بها. قل نعم. القائمة موجودة في `.vscode/extensions.json` وهي قصيرة:

|ملحق |ماذا يفعل |
|--- |--- |
|أجمل |تنسيقات Markdown بحيث تبدو ملفات الجميع متشابهة |
|معاينة Markdown المحسنة |معاينة جنبًا إلى جنب أثناء الكتابة |
|حتى أفضل TOML |تسليط الضوء على بناء الجملة لـ `netlify.toml` |
|تودو تري |يجمع كل `TODO:` في المشروع في لوحة واحدة |

::: tip
قم بتشغيل **التنسيق عند الحفظ** في إعدادات VS Code. ستقوم Prettier بعد ذلك بتنظيف Markdown في كل مرة تضغط فيها على "حفظ" ولن تضطر أبدًا إلى التفكير في التباعد مرة أخرى.
:::

## حساب GitHub {#a-github-account}

مجاني، وتحتاج إلى واحد لفتح طلب سحب. قم بالتسجيل في [github.com](https://github.com).

إذا كنت تخطط للدفع من جهازك بدلاً من التحرير في المتصفح، فقم بإعداد مفتاح SSH أيضًا - GitHub يغطيه [سيرة خاصة](https://docs.github.com/en/authentication/connecting-to-github-with-ssh) بشكل أفضل مما نستطيع.

## ما لا تحتاجه {#what-you-do-not-need}

أنت تكتب Markdown، وليس رمزًا. لا تحتاج إلى معرفة Vue أو TypeScript أو أي شيء حول كيفية عمل VitePress داخليًا. إذا كان بإمكانك كتابة مشاركة في المنتدى، فيمكنك كتابة صفحة هنا.
