# المزيد من الموارد {#more-resources}

كل شيء أدناه خارجي. لقد قمنا بربطها بدلاً من إعادة صياغتها لأنه يتم الحفاظ عليها جميعًا بشكل أفضل من نسخة منها هنا.

## Markdown {#markdown}

- [مرجعي مشترك](https://commonmark.org/help/) - بناء الجملة بالكامل في صفحة واحدة، مع محرر مباشر
- [Markdown الدليل](https://www.markdownguide.org/basic-syntax/) - نفس الشيءالأرض، موضحة بمزيد من التفصيل
- [VitePress Markdown التمديدات](https://vitepress.dev/guide/markdown) - الإضافات التي تعمل فقط على هذا الموقع

## Git {#git}

- [Pro Git](https://git-scm.com/book/en/v2) - الكتاب الرسمي، مجانًا عبر الإنترنت. تغطي الفصول من 1 إلى 3 كل ما يحتاجه المساهم
- [اللعنة، (جيت)!](https://ohshitgit.com/) - كيفية التراجع عن الشيء المحدد الذي ارتكبته للتو بشكل خاطئ
- [Learn Git Branching](https://learngitbranching.js.org/) - مصور تفاعلي، وهو حقًا أسرع طريقة لفهم الفروع
- [git-scm reference](https://git-scm.com/docs) -كل أمر وكل علامة

## GitHub {#github}

- [GitHub Quickstart](https://docs.github.com/en/get-started/quickstart)
- [Introduction to GitHub](https://github.com/skills/introduction-to-github) - دورة تدريبية عملية مجانية تنتهي بفتحهاطلب سحب حقيقي
- [Connecting to GitHub with SSH](https://docs.github.com/en/authentication/connecting-to-github-with-ssh)

## VitePress {#vitepress}

- [VitePress](https://vitepress.dev)
- [تشكيلة المواضيع الافتراضية](https://vitepress.dev/reference/default-theme-config) - كل خيار في `.vitepress/config.mts`
- [Internationalisation](https://vitepress.dev/guide/i18n) - كيفية عمل مجلدات اللغة
