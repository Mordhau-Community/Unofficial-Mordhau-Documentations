# معلومات عنا {#about-us}

Mordhau Guides هو مشروع توثيق غير رسمي للعبة Mordhau،
تمت كتابته وصيانته بواسطة مساهمين متطوعين.

معظم ما هو مطلوب لتشغيل خادم مخصص أو استخدام RCON أو العمل مع SDK
موجود منذ سنوات، ومنتشر عبر سلاسل رسائل Discord ومشاركات المنتدى وملاحظات
الخاصة. يتم فقدان هذه المادة بسهولة: يتم تمرير الخيط بعيدًا عن متناول اليد، ويتوقف مالك خادم
عن التشغيل. يجمعها المشروع في مكان واحد، بترتيب
ثابت، ويبقيها محدثة أثناء تصحيح اللعبة.

المشروع مستقل. إنها ليست تابعة لـ Triternion أو معتمدة من قبل
، وكل صفحة مكتوبة بواسطة اللاعبين وليس بواسطة المطورين.

المساهمات مفتوحة لأي شخص، وأغلب ما هو مفيد صغير: تصحيح
، خطوة مفقودة، صفحة مترجمة إلى لغة أخرى.
[كيفية المساهمة](/ar/contributing/) يحدد العملية.
