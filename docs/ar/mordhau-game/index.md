# لعبة Mordhau {#mordhau-game}

Mordhau هي لعبة قتال وتقطيع (hack-and-slash) جماعية تدور في العصور الوسطى. جذبت اللاعبين بميكانيكيات القتال (Combat Mechanics) الغامرة، والمؤثرات البصرية المميزة، وأسلوب اللعب الاستراتيجي. طورتها Triternion، وتتيح للاعبين خوض معارك اشتباك قريبة مكثفة، وتخصيص الشخصيات، وتجربة أوضاع لعب (Game Modes) متعددة تشمل المعارك واسعة النطاق، والمبارزات (Duels)، والمهام التعاونية.

منذ إصدارها عام 2019، تكوّن حول اللعبة مجتمع نشط من اللاعبين وصانعي التعديلات (Modders) الذين يطوّرون التجربة عبر الخوادم المخصصة (Custom Servers)، والتعديلات (Mods)، وتحسينات أسلوب اللعب.

لفهم طريقة عمل القتال، اقرأ [ميكانيكيات القتال (Combat Mechanics)](/ar/combat-mechanics/).
وللتعرف على الجوانب التي لا توثقها اللعبة، اقرأ [نقص توثيق Mordhau](/ar/mordhau-lack/).
