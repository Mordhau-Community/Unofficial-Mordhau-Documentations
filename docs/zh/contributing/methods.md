# 贡献方法 {#contribution-methods}

这里有不止一种方法可以提供帮助，并且并非所有方法都涉及克隆存储库。选择与您想要花多少时间相匹配的选项。

## 1. 打开问题 {#1-open-an-issue}

最省力的选项，老实说，当您发现问题时，这是最有用的选项。发现某个命令不再起作用？死链接？一个自相矛盾的页面？打开 [问题](https://github.com/Mordhau-Community/Unofficial-Mordhau-Documentations/issues) 并描述它。

一个好的问题可以说明您在哪个页面、您期望什么以及实际发生了什么。您不必知道修复方法。

## 2. 从浏览器编辑页面 {#2-edit-a-page-from-the-browser}

本网站的每个页面底部都有一个 **编辑此页面** 链接。单击它会在 GitHub 的编辑器中打开该确切文件。进行更改，写一个简短的注释来描述它，GitHub 将分叉存储库并为您打开拉取请求。

对于拼写错误、损坏的链接、读起来很糟糕的句子或小的补充，这是正确的选择。无需终端，无需安装，无需设置。

## 3. 本地工作 {#3-work-locally}

一旦您要更改多个文件（或添加页面，或触摸侧边栏），就值得在您的计算机上设置项目，以便在发送之前可以看到结果。[导言](/zh/contributing/) 遍历克隆和开发服务器。

在本地工作：

- 添加全新页面
- 重组部分
- 编辑 `.vitepress/config.mts` 中的导航
- 添加图像

## 4. 翻译 {#4-translate}

该网站已经以英语、阿拉伯语、法语、日语、俄语和中文运行，但大多数翻译的文件夹远远落后于英语。用您实际使用的语言填写页面是您可以在这里做的最有价值的事情之一。

翻译在 `docs/<language>/` 中进行，反映了英语结构。将英文文件复制到您的语言文件夹中的匹配路径并翻译正文。保留 frontmatter 键——只翻译值。

::: warning
请不要提交机器翻译的页面。由会说该语言的人写出的粗糙页面胜过看起来流利但技术术语错误的页面，而且我们无法审查我们没人读过的语言。
:::

## 5. 分享您已经知道的内容 {#5-share-what-you-already-know}

许多 Mordhau 知识都位于 Discord 线程和旧论坛帖子中。如果您已经运行服务器多年，或者您已经弄清楚了一些关于 SDK 的内容但没有写下来，那么您不需要自己将其变成精美的页面。将其放入 [Discord](https://discord.gg/zuX58yRV84) 或将其粘贴到问题中，有人会帮助塑造它。

这个项目的一半意义是在认识它们的人继续前进之前收集这些东西。
