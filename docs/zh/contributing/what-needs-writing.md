# 还需要写什么 {#what-still-needs-writing}

诚实地列出差距，因此任何想要做一些有用的事情的人都可以
选择一个而不是猜测。

剩下的大部分都不是写作。它是测量：必须是的数字
由打开游戏的人在游戏中进行测试，因为它们随着
补丁，没有人应该发明它们。如果您可以运行测试，那么您就是
能够缩小差距的人。

::: tip
在开始之前，[准确性规则](/zh/contributing/terms-rules) 涵盖
这里最重要的一件事是：标记任何您无法验证的内容
而不是将其四舍五入为一个可靠的数字。
:::

## 玩家指南 {#player-guides}

**武器编号。** [武器和装载](/zh/weapons/) 涵盖如何选择武器
武器并故意不携带统计表。按类型、饱和度和
发布时间和积分成本都缺失。这是最大的单
网站上的差距。

**装甲。** 每层的成本、重量以及对抗性能如何
每种伤害类型。当前武器页面内的一段。

**福利。** 根本没有任何参考。每个人做什么，花费多少，以及
是否值得你为此放弃的盔甲。

**地图。** 除了服务器指南轮换列表中的名称之外没有任何内容。布局，
每个地图和每个模式的目标和标注。

**进度。** 等级、金币以及解锁时间。

## 服务器指南 {#server-guides}

**管理命令。** [RCON 向导](/zh/rcon-guide/) 涵盖了它的命令
它所经历的任务的需求。可用内容的完整参考，
而每个人实际所做的事情还不存在。

**托管模组。** 如何运行模组服务器，以及运行时会出现什么问题。

**性能。** 服务器指南涉及滴答率。其他一切关于
运行一个在满玩家数量的情况下保持流畅的服务器是没有记录的。

## 改装 {#modding}

[SDK 指南](/zh/mordhauSDK-guide/) 明确表示它尚未完成，并且
这是该网站上最薄的部分。发布到 mod.io 及其基础知识
构建自定义地图都值得拥有。

## 翻译 {#translations}

阿拉伯文、法文、日文、俄文和中文各有几页
对抗英语部分的两打。翻译后的页面不需要任何技术
超越语言的知识，以及
[缴款方法](/zh/contributing/methods) 涵盖了该语言如何
文件夹工作。

请不要机器翻译。来自讲该语言的人的粗略页面
语言比流利但弄错术语的语言更有价值。

## 完成后的样子 {#what-finished-looks-like}

当从未做过某事的人可以开始关注该页面时，该页面就完成了
不打开任何其他东西就完成，当上面的每个数字都出现时
来自测试或标记为未经测试。

这比这里现有的大多数标准都要高。页面变得更好
正在被纠正，所以诚实地指出其差距的初稿是值得的
总比没有好。
