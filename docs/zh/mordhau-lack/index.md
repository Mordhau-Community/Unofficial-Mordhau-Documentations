# Mordhau 缺少 {#mordhau-lack}

Mordhau 已被充分记录为可玩的游戏，而几乎没有记录为
运行的游戏。除了加入服务器之外的所有事情（托管服务器、管理服务器、为其构建
或在服务器损坏时修复服务器）都没有维护官方参考。

## 空白处是 {#where-the-gaps-are}

**专用服务器。** 通过 SteamCMD 安装，`Game.ini` 的形状，
必须打开哪些端口以及每个端口是什么for：所有这些都必须是
，从经常彼此不一致的论坛帖子中重建。

**RCON.** 协议有效并且命令存在，但是没有
的权威列表，没有记录哪些命令发生了更改，也没有
对名称未描述其用途的命令的解释。

**SDK。**足以打开编辑器找到。足以完成并发布
工作地图或 mod 主要是口头传统。

**错误。** 失败消息很简洁，原因很少很明显。
大多数答案都存在于某处的 Discord 回复中，一次写给一个
人。

## 为什么它保持这种状态 {#why-it-stays-that-way}

文档通常是小型工作室丢弃的第一个东西，也是社区收集的最后一个
东西。它写起来很慢，永远不会完成，而且
每个移动值或重命名键的补丁都会再次使其部分内容过时
。

不过，知识并没有消失。它根本就没有得到过写下
任何地方耐用。它存在于滚动超出范围的线程中，存在于
已经沉寂的论坛上，存在于通过
反复试验解决了问题并早已停止播放的服务器所有者的记忆中。当他们离开时，
也随之离开。

## 成本是多少 {#what-that-costs}

对于任何想要运行或构建某些东西的人来说，入门成本很高。每隔几周就会从头开始回答相同的
问题。服务器配置错误
，因为正确的设置从未记录在任何可找到的地方。还有
在到达本来有趣的部分之前就放弃的人。

## 这个网站对此做了什么 {#what-this-site-does-about-it}

它把缺失的一半写下来。[指南](/zh/dedicated-server-guide/) 是
的尝试，而 [捐款](/zh/contributing/) 是如何关闭剩余间隙
的。
