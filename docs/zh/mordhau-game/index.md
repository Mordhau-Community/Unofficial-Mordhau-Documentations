# Mordhau 游戏 {#mordhau-game}

Mordhau 是一款多人中世纪砍杀游戏，以其身临其境的战斗系统、令人惊叹的视觉效果和策略性吸引了
玩家。
游戏玩法。Mordhau由Triternion开发，让玩家有机会与
进行激烈的近战战斗，自定义角色，并探索各种
游戏模式，包括大规模战斗、决斗和合作任务。

自 2019 年发布以来，该游戏已经建立了一个由玩家
和模组制作者组成的专门社区，他们热衷于通过定制
服务器、模组和游戏改进来增强体验。

对于游戏未记录的内容，请参阅 [缺少](/zh/mordhau-lack/)。
