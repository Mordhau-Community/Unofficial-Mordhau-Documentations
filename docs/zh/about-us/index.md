# 关于我们 {#about-us}

Mordhau 指南是游戏 Mordhau、
的非官方文档项目，由志愿者贡献者编写和维护。

运行专用服务器、使用 RCON 或使用 SDK
所需的大部分内容已经存在多年，分散在 Discord 线程、论坛帖子和
私人笔记中。这些材料很容易丢失：线程滚动到超出范围，
服务器所有者停止播放。该项目以固定的
顺序将其收集在一个地方，并在游戏修补时保持最新状态。

该项目是独立的。它不隶属于Triternion，也没有得到
的认可，并且每个页面都是由玩家而不是开发人员编写的。

贡献对任何人开放，大多数有用的内容都很小：
更正、缺少的步骤、翻译成另一种语言的页面。
[如何作出贡献](/zh/contributing/) 列出了该过程。
