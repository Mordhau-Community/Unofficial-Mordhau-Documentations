# 专用游戏服务器提供商 {#dedicated-game-server-providers}

如果您不想运行 [您的服务器](/zh/dedicated-server-guide/)，这些公司可以租用带有 Web 控制面板的 Mordhau 服务器。您每月为每个插槽付费，他们处理机器、更新和端口，并且您在浏览器中获得配置编辑器和控制台。

以下主机是 Mordhau 社区多年来使用的主机。

## 选择一个 {#choosing-one}

在预付六个月费用之前，有一些值得检查的事项：

**硬件在哪里。** Ping 是玩家首先会注意到的事情。选择一个靠近您希望一起玩的人的位置，而不是靠近您。

**是否获得文件访问权限。** 某些面板仅通过表单公开少量设置。如果您想正确编辑 `Game.ini` 和 `Engine.ini`，您需要 FTP 或真正的文件管理器。

**RCON是否可用。** 大多数面板都有内置控制台，但如果您想连接自己的[RCON 客户端](/zh/rcon-guide/)，您需要主机为您提供端口并让您访问它。

**更新如何工作。** Mordhau 补丁会破坏运行旧版本的服务器。查明主机是否自动更新或是否由您自行更新。

**插槽如何计费。** 几乎所有这些都按插槽收费。一台 64 插槽服务器的成本大约是 16 插槽服务器的四倍，因此请诚实地了解自己实际会出现多少人。

## 或者自己托管 {#or-host-it-yourself}

它是免费的，而且并不是特别难 - [专用服务器指南](/zh/dedicated-server-guide/) 会完成整个过程。您需要一台保持开机状态并能够转发三个端口的机器。如果您已经有 VPS 或备用盒子，那么大部分工作就完成了。
