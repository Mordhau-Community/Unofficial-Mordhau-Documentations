## 运行服务器 {#running-a-server}

- [LinuxGSM 软件 Mordhau 配置](https://github.com/GameServerManagers/Game-Server-Configs/tree/master/Mordhau) — 包含每个默认值的参考 `Game.ini`。用于检查设置应该是什么样子
- [LinuxGSM 软件](https://linuxgsm.com/servers/mhserver/) — Linux 服务器的管理脚本，为您处理更新和重新启动
- [cm2网络/ZXXPH000XZ](https://github.com/CM2Walki/Mordhau) — Docker 映像，如果您希望在容器中运行它
- [SteamCMD 文档](https://developer.valvesoftware.com/wiki/SteamCMD) — Valve 自己的参考
- [麦克风](https://github.com/Tiiffi/mcrcon) — 我们的 [RCON 向导](/zh/rcon-guide/) 中使用的 RCON 客户端
- [GPortal 管理员命令列表](https://www.g-portal.com/wiki/en/mordhau/) — 管理和 RCON 命令及其语法
