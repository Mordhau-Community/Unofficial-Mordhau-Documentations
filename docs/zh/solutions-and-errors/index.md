# 解决方案和错误 {#solutions-and-errors}

常见问题以及通常如何解决这些问题。首先是服务器问题，因为这是大多数问题的来源。

::: tip
在执行其他操作之前，请先阅读日志。大多数时候，它准确地说明了问题所在。

- **服务器：** `Mordhau/Saved/Logs/` 在服务器中安装
- **客户端 (Windows):** `%LOCALAPPDATA%\Mordhau\Saved\Logs\`

启动服务器`-log` 并且它会打印到控制台，这比事后读取文件要容易得多。
:::

## 服务器问题 {#server-problems}

### 服务器没有出现在浏览器中 {#the-server-does-not-appear-in-the-browser}

迄今为止最常见的一种，它几乎总是**信标或查询端口**。

游戏端口打通不够。所有三个 UDP 端口都必须打开并转发：

|港口|协议|被阻止的后果 |
|--- |--- |--- |
|7777 |UDP |没有人可以连接 |
|15000 | 15000UDP |服务器没有出现在浏览器中|
|27015 | 27015UDP |服务器不出现，或出现时没有任何信息 |

按以下顺序进行操作：

1. 服务器是否实际运行？检查控制台输出。
2. 机器本身的防火墙允许吗？Windows 防火墙会在首次启动时阻止服务器，并且无需阅读即可轻松忽略该提示。
3. 路由器上的所有三个端口是否都作为 **UDP** 转发到正确的内部 IP？
4. 机器的本地IP是否发生变化？动态主机配置协议重新分配地址和转发规则然后什么也不指向。为服务器提供静态本地 IP 或 DHCP 保留。

如果它在您自己的网络上工作，但在外部网络上不起作用，并且转发绝对正确，则您的 ISP 可能让您处于 CGNAT 后面。您无法通过它进行托管，并且任何配置都不会改变它 - 您需要一个 VPS。

### 配置更改不起作用 {#config-changes-do-nothing}

您在服务器运行时编辑了 `Game.ini`。

Mordhau 将其配置保留在内存中，并在关机时将其写回，用启动时加载的内容覆盖您的文件。停止服务器，编辑，然后启动它。

### 服务器启动后立即关闭 {#the-server-closes-immediately-after-starting}

读取日志。通常为以下之一：

- **端口已在使用中。** 另一台服务器或未退出的先前实例。检查是否有杂散进程，或移动到不同的端口。
- **缺少文件。** 重新运行 SteamCMD 命令，并在末尾添加 `validate`。
- **格式错误的 `Game.ini`。** 节标题中的拼写错误，或应为数字的值。

### 没有人可以连接，但服务器已列出 {#nobody-can-connect-but-the-server-is-listed}

游戏端口，7777 UDP。与上面相同的检查。

如果已列出并且连接启动但立即断开，请检查 `ServerPassword` 是否设置为您忘记的内容。

### 管理命令被拒绝 {#admin-commands-are-rejected}

首先键入 `adminlogin` 和 `AdminPassword` 中的密码。在此之前，没有其他方法可以工作。

如果仍然拒绝，您在服务器运行时编辑了密码，它被覆盖了。见上文。

### RCON 将不会连接 {#rcon-will-not-connect}

**连接被拒绝** — RCON 未监听。需要在`Game.ini`中设置`RconPort`并重新启动服务器。

**连接超时** — 防火墙。请注意，与其他三个端口不同，RCON 端口是 **TCP**，因此覆盖游戏端口的规则不会覆盖它。

**身份验证失败** — 密码错误。如果您将 `RconPassword` 留空，服务器会在启动时生成一个您无法知道的随机值。明确设置并重新启动。

有关 [RCON 页面](/zh/rcon-guide/) 的更多详细信息。

### 服务器正在运行旧版本 {#the-server-is-running-an-old-build}

Mordhau 客户端无法加入不同版本上的服务器。打完补丁后，重新运行：

```bash
./steamcmd.sh +force_install_dir ~/mordhau-server +login anonymous +app_update 629800 validate +quit
```

`+force_install_dir` 必须先于 `+login` 或 SteamCMD 忽略它并更新错误文件夹。

### 完整服务器 {#performance-is-bad-with-a-full-server}

的性能很差 检查 `Engine.ini` 中的 `NetServerMaxTickRate`。如果它设置得高于硬件可以承受的水平，服务器就会落后，每个人都会遇到橡皮筋——稳定的 60 感觉比不稳定的 120 好得多。

Mordhau 很大程度上是单线程限制，因此单核时钟速度比核心数量更重要。具有许多慢速核心的廉价 VPS 并不适合。

## 客户端问题 {#client-problems}

::: info
这一节比服务器部分薄，因为我们这里大多数人运行服务器而不是支持客户。如果您修复了未列出的问题，[加起来](/zh/contributing/methods)。
:::

### 游戏无法启动 {#the-game-will-not-start}

1. 通过 Steam 验证游戏文件 — 右键单击 Mordhau，属性，已安装文件，验证完整性。
2. 更新显卡驱动程序。
3. 重新启动。确实，对于反作弊问题，这比应有的修复更频繁。

### 反作弊错误 {#anti-cheat-errors}

Mordhau 使用 Easy Anti-Cheat，大多数启动失败都可以追溯到它。

- 再次运行游戏文件夹中的 EAC 安装程序。
- 尝试以管理员身份启动 Steam。
- 检查您的防病毒软件是否未隔离游戏或 EAC。安全软件将反作弊误认为是恶意软件很常见，因为它们的行为相似。

### 比赛中断线 {#disconnected-during-a-match}

- 如果是某一台特定服务器，则是该服务器，而不是您。
- 如果是每个服务器，请总体测试您的连接。Wi-Fi 是常见的罪魁祸首——如果可以的话，尝试使用电缆。
- 数据包丢失显示为橡皮筋，并且在显示为断开连接之前不会注册命中。

### 帧率较差 {#poor-frame-rate}

首先降低阴影和观看距离，它们在视觉差异最小的情况下成本最高。前线服务器满载是游戏中最糟糕的情况 - 如果它只是在那里卡住，那就是负载，而不是故障。

## 仍然卡住 {#still-stuck}

将其带到 [Discord](https://discord.gg/zuX58yRV84)。要快速获得有用的答案，请包括：

- 您正在做什么以及发生了什么
- 您的平台，以及是否是客户端或服务器问题
- 日志的相关部分，而不是它的屏幕截图
- 您已经尝试过的内容

如果您解决了修复问题，请返回并在此处添加。此页上几乎所有内容都在这里，因为它发生在某人身上并且他们把它写了下来。
