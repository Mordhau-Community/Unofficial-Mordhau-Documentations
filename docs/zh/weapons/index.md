# 武器和装备 {#weapons-and-loadouts}

Mordhau 为您提供固定的积分预算，并让您可以将其花在
武器、盔甲和津贴。一切都在争夺同一个池，所以加载
是一系列交易而不是购物清单：较重的装甲意味着
更便宜的武器，更多的津贴意味着更少的装甲。

本页是关于如何思考该交易的。每种武器是什么
数字方面的工作是一项单独的工作，而本页尚未完成这项工作 - 请参阅
[此页面仍然需要的内容](#what-this-page-still-needs) 在底部。

## 家人 {#the-families}

**单手操作。** 触及范围更短，发条速度更快，并且可以解放您的另一只手
为了盾牌。快速武器更难阅读，也更难
[拖动](/zh/combat-mechanics/) 很有用，因为动画较少
拉紧。

**双手。** 游戏中间。足以应对大多数战斗，
足够的饱和长度，加速和阻力实际上可以做一些事情，并且足够
交易对你有利的伤害。

**长柄武器。** 范围是整个争论的焦点。站在他们的位置你就赢了
无法联系到您并惩罚他们关闭。在走廊或人群中
是决定性的；对抗进入你射程的人是很痛苦的。

**远程。** 弓和十字弓。与近战完全不同的游戏，并且
最有可能让你在前线服务器上不受欢迎的一个。

**护盾。** 用进攻选择换取更大的防守窗口。他们
改变你对待别人的方式，而不是改变你的战斗方式。

**投掷物和工具。** 燃烧弹、投掷武器和工具箱，
建造尖刺和修复目标，在前线很常见。

## 到达率是首先要考虑的 {#reach-is-the-first-thing-to-look-at}

[作战力学](/zh/combat-mechanics/) 页面指出
站在他们范围的边缘而在自己范围之内的价值比
任何佯攻。你携带的武器决定了优势在哪里。

较长的武器并不能简单地击败较短的武器。它以距离取胜
是为这个距离而建造的，并且在这个距离内丢失，因为相同的长度
让某人远离的是被墙壁、队友和他们的人绊住的长度
当他们介入时身体。选择武器主要是选择你的距离
打算在那里战斗，然后在那里实际战斗。

## 速度改变你能做什么，而不仅仅是你做事的速度 {#speed-changes-what-you-can-do-not-just-how-fast-you-do-it}

缠绕长度是加速和阻力的原材料。慢速武器有一个
长发条，这是更多的动画来操纵，所以它的摆动可以制作
比看起来更早或更晚着陆。快速武器的作用较小
与对手合作，并通过简单地在招架之前到达来获胜。

这就是为什么两个拥有不同武器的玩家都可以做某事
明智的，以及为什么复制装载而不复制它所构建的游戏风格
因为通常情况会很糟糕。

## 盔甲是从同一个口袋里买的 {#armour-is-bought-from-the-same-pocket}

护甲是分等级消耗的，进入其中的每一点都是一个点，而不是一个点
进入你的武器或你的特权。较重的装甲吸收更多但成本更高
点和运动。

::: warning
Mordhau 中的伤害不是一个单一的数字：武器会造成不同类型的伤害
伤害和护甲的抵抗力不同，这就是为什么武器会撕裂
一个没有装甲的对手在面对一个重装甲的对手时会感到毫无用处。这
特定的交互值得在游戏中根据您实际的构建进行检查
运行，因为补丁会调整它们。
:::

## 构建有效的负载 {#building-a-loadout-that-works}

1. **选择你想要战斗的距离**，然后选择拥有它的武器。
2. **把剩下的钱花在盔甲上**，而不是相反。已构建装载
首先，盔甲往往会给你留下你不喜欢的武器。
3. **最后才是福利**，只有那些你会注意到的。一项可以拯救你的福利
一旦一场比赛花费半秒，你就会损失整场比赛的护甲。
4. **在评判之前先运行几个小时。**大多数加载都感觉不对
第一个小时，因为他们要求你以不同的方式战斗。

如果你是新手，请拿一些带有中型装甲的双手，然后离开
单独优化，直到战斗本身不再是困难的部分。

## 此页面还需要什么 {#what-this-page-still-needs}

本页介绍如何选择。它还没有携带数字：每武器
伤害、结束和释放时间、点数成本或护甲值。

这些需要有人可以在游戏中测试它们并记录它们的实际情况
测量，因为它们会随着补丁的变化而变化，并且自信错误的表会更糟
比没有桌子。如果您运行了这些测试，那么这确实是有价值的
贡献 — [如何捐款](/zh/contributing/) 涵盖如何发送它，
和 [准确性规则](/zh/contributing/terms-rules) 封面标记任何东西
你无法验证。
