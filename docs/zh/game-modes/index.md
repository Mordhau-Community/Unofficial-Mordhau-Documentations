# 游戏模式 {#game-modes}

Mordhau 的模式大致分为四组： 团队战斗的目标模式
在地面上，团队模式中唯一的目标是另一个团队，模式中
每个人都是独立的，而敌人就是游戏本身。

您在服务器浏览器中看到的内容取决于人们托管的内容
时间。大目标模式承载着大多数人口，并且
较小的主要生活在社区服务器上。

::: warning
阵容随着补丁的变化而变化，社区服务器经常运行修改
规则。将此页面视为每种模式的用途，而不是关于其用途的承诺
今晚在浏览器中。
:::

## 目标模式 {#objective-modes}

### 前线 {#frontline}

大多数人在谈论 Mordhau 时指的是这种模式。两队推一条线
地图上的多个占领点，占领一个后会移动前方和生成点
与它。死亡很便宜，因为重生是一波又一波的，所以形状是
前线比赛是一群人的移动，而不是一系列的决斗。

这也是游戏中最吵闹、最混乱的地方，也是最糟糕的地方。
学习战斗。你会对那些你从未见过的人死去。那不是你玩的
糟糕的是，这就是模式。

### 入侵 {#invasion}

不对称。一个团队按顺序攻击一系列目标，而另一个团队
持有它们，并运行计时器。攻击者必须完成整个链条才能
赢;防守者只能拖延。

比前线更长、更有条理，目标往往集中在
战斗到地图本身很重要的地方。

## 团队模式 {#team-modes}

### 团队死亡竞赛 {#team-deathmatch}

两队，得分限制，没有超越另一队的目标。重生是
快的。服务器地图列表上的 `TDM_`。

### 小冲突 {#skirmish}

基于回合，并且没有重生。死了你就坐在外面，这
立即改变人们的游戏方式——没有人会用生命换取杀戮
是他们唯一的一个。回合较短，节奏更接近一系列小回合
参与度高于 Frontline 的 scrum。服务器地图列表上的 `SKM_`。

## 每个人都为了自己 {#everyone-for-themselves}

### 所有人免费 {#free-for-all}

没有团队，没有目标。游戏中实际练习的最佳地点
战斗，因为每分钟有大量交战，而没有人参与
依赖你。服务器地图列表上的 `FFA_`。

预计在已经与其他人战斗时会受到攻击。学习摆脱困境
在这里，你赢得一场战斗是一项真正的技能。

### 大逃杀 {#battle-royale}

最后一名站立的玩家，在缩小的游戏区域中，从你发现的任何东西开始
而不是您构建的负载。

## 对抗比赛 {#against-the-game}

### 部落 {#horde}

合作的。一支球队顶住了人工智能的浪潮，随着比赛的进行，人工智能的难度越来越大
继续，在波浪之间用黄金来购买更好的装备。宽容，并且
在没有真正的对手惩罚的情况下熟悉武器的合理方法
每一个错误。

## 决斗 {#duels}

与其说是菜单中的一种模式，不如说是一种约定。对决服务器很普通
为一对一战斗而设置的服务器，由服务器上的人们执行礼仪
他们：你等待轮到你，你鞠躬，并且你不打断战斗
进步。如果该约定是，请参阅 [词汇表](/zh/glossary/)
对你来说是新的。

这是人们真正提高战斗系统的地方，而且它是
[作战力学](/zh/combat-mechanics/) 页面上的机制在哪里
值得好好学习。

## 从哪里开始 {#where-to-start}

如果您刚刚安装游戏，请选择浪费最少资源的顺序
时间大致是：

1. **部落**或机器人比赛，以习惯挥杆和招架
没有任何利害关系。
2. **对所有人免费**，针对战斗量。
3. **前线**，一旦不断死亡就不再告诉你任何事情。
4. **决斗服务器**，当您想要修复特定问题时。

大多数人都会直接跳到前线，这也是为什么大多数人都会这样做。
人们在最初的十个小时里确信战斗是随机的。

## 在您自己的服务器上运行这些 {#running-these-on-your-own-server}

服务器映射名称是模式前缀加上映射名称，因此 `FFA_Grad` 是 Grad
所有人免费。[专用服务器指南](/zh/dedicated-server-guide/) 有
地图旋转设置和完整的前缀列表。
