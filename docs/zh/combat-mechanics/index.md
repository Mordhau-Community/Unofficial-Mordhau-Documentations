# 战斗机制 {#combat-mechanics}

Mordhau 的战斗在你的前十个小时里看起来就像是按下按钮，然后突然就不是了。本页大致按照值得学习的顺序解释了下面实际发生的事情。

::: warning
确切的数字 - 耐力成本、时间 windows - 在补丁中进行调整。将此处的具体数字视为近似值，将概念视为可靠的。如果您发现某个版本已过时，请输入 [纠正它](https://github.com/Mordhau-Community/Unofficial-Mordhau-Documentations/issues)。
:::

## 三种攻击 {#the-three-attacks}

你扔出的所有东西都是三件事之一：

**打击** - 水平摆动。它来自哪一侧取决于您启动鼠标时移动鼠标的方式。

**开销** — 从上方落下。弧线更短，更难拖动，在狭窄的空间里很尴尬，因为它会挂在天花板和队友身上。

**刺** - 推力。狭窄、快速，并且可以穿过秋千可能撞到墙上的间隙。

每次攻击都会经历三个阶段：武器被拉回时的**结束**，当它实际上可以伤害某人时**释放**，以及当你卡在收起武器时的**恢复**。下面几乎每个机制都是关于操纵这三个 windows 之一。

## 防御 {#defence}

### 招架 {#parry}

右键单击。盾牌图标会在你的十字准线上闪烁，在这个短暂的窗口中，几乎所有击中你武器的东西都会被偏转——挥舞、刺伤、箭。

招架不是免费的。它会消耗你的耐力，也会消耗攻击者的耐力。两个除了挥杆什么都不做的球员招架和招架都在消耗，谁先耗尽谁就有大麻烦。

::: warning
招架窗口比向您袭来的秋千短得多。这是关于 Mordhau 战斗的最重要的事实，也是拖动和加速起作用的原因。当你“看到”挥杆开始时你无法招架，当它即将“落地”时你必须招架。
:::

### 密室 {#chamber}

你不用招架，而是在攻击连接之前，沿着与传入攻击相同的角度进行攻击。你的武器会偏转他们的武器并直接滚动到你自己的攻击中。

张伯宁的作用与格挡的作用相同，同时又给你主动权，这就是为什么优秀的玩家会不断这样做。这也是无情的——如果角度或时机错误，你就会吃到苦头。

### 还击 {#riposte}

成功招架后立即获得的快速攻击。它比正常挥杆更快，这就是为什么值得进行格挡而不是仅仅后退。

有两件事要知道：还击不能佯攻或变形，所以它在你投掷它的那一刻就被承诺了。作为交换，它带有超级装甲，这意味着你不会因为别人的攻击而退缩——当你寡不敌众时很有用，因为你可以进行交易而不是永远被打断。

### 踢 {#kick}

踢击击败持有的招架。对抗那些正在龟缩的人——坐在他们的街区后面等待——一脚踢开他们，给你一个免费的打击。

它很慢，如果你把它扔给某人不阻止你将会受到惩罚。

## 进攻 {#offence}

### 佯攻 {#feint}

在结束时取消你的攻击。他们致力于格挡从未到达的挥杆，现在他们正在恢复，面前什么也没有。

佯攻窗口会保持打开状态，直到结束的最后 50 毫秒左右，因此您可以将其保留得很晚。每次都消耗体力。

### 变形 {#morph}

开始一次攻击，并在结束时将其转变为另一种攻击 - 攻击变为刺击，反之亦然。体力7左右。

假动作让他们无法招架，而变形则让他们招架错误的东西。他们的挥击时机恰到好处，但刺击却来了。

### 加速 {#accel}

在释放时将身体转入挥杆状态。武器在其弧线中较早连接，因此命中比动画显示的要早，而他们的招架来得太晚。

### 拖动 {#drag}

相反。转身远离秋千，将其伸展，使其落在释放窗口的最末端。当它看起来应该击中时，他们进行了招架，招架过期了，武器随后到达。

加速和阻力的结合是Mordhau的战斗享有盛誉的原因。动画不是一个可靠的时钟——攻击者通过移动鼠标来控制攻击何时落地，而读取这是大部分技能。

## 耐力 {#stamina}

耐力是这一切背后的资源。当你执行以下操作时，它会耗尽：

- 招架
- 被格挡
- 佯攻或变形
- 完全错过一次挥杆
- 跳跃

在零时，你被解除武装 - 你的武器从你手中被击落，你在足够长的时间内毫无防御能力被杀了。在 Mordhau 中输掉一场战斗通常先是耐力损失，然后才是生命值损失。

实际的后果是不断的挥杆输给了刻意的挥杆。每一次失手都是你白白付出的体力。

## 步法 {#footwork}

距离比本页上的任何技术都更有效。

不同的武器有不同的攻击范围，站在他们的边缘而自己却在自己的里面比任何佯攻都更有价值。退出挥杆通常比招架要好，因为它根本不消耗你的耐力。

攻击时移动会改变攻击。介入会缩短有效饱和时间，后退则会延长有效饱和时间。将其与加速和阻力相结合，相同的挥杆可能会在明显不同的时间到达。

## 为了学习 {#order-to-learn-this-in}

不要试图一次吸收所有内容。大致：

1. **可靠地招架。** 在您能够始终如一地阻止直接攻击之前，其他一切都不重要。
2. **反击。** 招架，反击。仅此一点就是一个有效的游戏计划。
3. **注意你的耐力。** 停止在空中摆动。
4. **佯攻。** 一种击败靠反射招架的人的工具。
5. **加速并拖动。** 当您击中时开始玩。
6. **Chamber.** 最后，因为它是最难的，没有它你也可以赢得很多战斗。
7. **步法。** 但你应该一直在做这件事。
