# 词汇表 {#glossary}

Mordhau 的社区词汇，以及此站点上出现的服务器和模组术语。如果您已阅读此处或 Discord 中的内容但不知道其含义，请从此处开始。

战斗术语在 [作战机械师](/zh/combat-mechanics/) 中得到了正确解释 - 这些是简短版本。

## 战斗 {#combat}

**加速** — 转变为挥杆，以便比动画显示的更早连接，击败招架。

**芭蕾舞演员** - 有人在挥杆过程中疯狂旋转，以在击球落地时进行伪装。有效，广泛不受欢迎。

**室** — 以相同的角度迎接来袭攻击，使其偏转并继续攻击。

**拖动** — 转身远离挥杆，以便在招架结束后尽可能晚地着陆。

**佯攻** — 在结束时取消攻击，让对手无法招架。

**退缩** — 攻击中途被击中打断。

**脚步** - 通过移动而不是使用武器来管理距离。几乎被所有人低估。

**超级装甲** — 您无法退缩的帧。还击有它。

**踢** — 打破已持有的招架。速度慢，如果发出气味就会受到惩罚。

**变形** - 将攻击转变为刺击，或者相反。

**开销** — 来自上方的攻击。

**招架** — 方块。右键，窗口短，消耗体力。

**恢复** —攻击发生后您陷入困境且脆弱的阶段。

**释放** — 武器实际上可以伤害某人的阶段。

**反击** — 成功招架后获得的快速攻击。无法佯攻或变形。

**刺入** — 推力。狭窄、快速、适合穿过间隙。

**耐力** — 招架、佯攻、变形和失误背后的资源。击中零，你就被解除武装了。

**打击** — 水平摆动。

**乌龟** — 坐在格挡后面从不攻击的人。踢他们。

**嘶嘶** — 一次错过的攻击。消耗体力并让你恢复。

**结束** — 武器在伤害任何人之前向后撤退的阶段。

## 游戏模式 {#game-modes}

**BR** — 大逃杀。

**FFA** — 所有人免费。每个人都反对每个人。

**前线** - 具有推动捕获点和重生波的目标模式。

**部落** - 合作，人工智能浪潮。

**入侵** - 攻击者通过一系列目标来对抗防御者。

**小冲突 (SKM)** — 回合制团队模式，无重生。

**TDM** — 团队死亡竞赛。

服务器地图名称将模式前缀与地图结合在一起，因此 `FFA_Grad` 是所有人免费的 Grad，`TDM_Camp` 是团队死亡竞赛中的 Camp。

## 装备 {#equipment}

**装载** — 角色构建。您花费固定点预算武器、盔甲和津贴。

**福利** - 用与装备相同的预算购买的被动特性。更多的津贴意味着更少的护甲。

**点数** — 装载的预算。一切都在争夺同一个池。

**工具箱** - 允许您构建尖峰和修复对象。常见于前线。

## 服务器 {#servers}

**信标端口** — 默认 UDP 15000。服务器浏览器如何到达您的服务器。阻止它，您的服务器就可以正常运行并且不可见。

**游戏端口** — 默认 UDP 7777。实际游戏流量。

**查询端口** — 默认 UDP 27015。浏览器如何读取您的玩家数量和服务器名称。

**Game.ini** — 主服务器配置文件，位于 `Saved/Config/WindowsServer/` 或 `Saved/Config/LinuxServer/` 下。

**Engine.ini** - 引擎级别设置，特别是滴答率。

**MaxSlots** — 玩家容量。

**地图旋转** — 服务器循环浏览的地图列表，每行一行 `MapRotation`。

**Playfab ID** — 用于管理命令的玩家标识符 Mordhau。不是 Steam ID。使用 `playerlist` 获取它们。

**RCON** — 远程控制台。无需在游戏中即可通过网络向服务器发送命令。请参阅 [RCON 向导](/zh/rcon-guide/)。

**SteamCMD** — Valve 的命令行工具。如何下载和更新服务器文件。

**滴答率** — 服务器更新世界的频率，以 Hz 为单位。越高越流畅，但 CPU 成本也越高。

**应用程序629800** — Steam 上的专用服务器。游戏本身是629760，混淆两者是经典的第一个错误。

## 模组 {#modding}

**mod.io** — Mordhau 用于分发模组的平台。

**Mordhau 编辑器** — 官方地图和模组创建工具，Unreal Engine 的版本。请参阅 [SDK 指南](/zh/mordhauSDK-guide/)。

**SDK** — 软件开发套件。在 Mordhau 对话中，它通常指编辑。

**UE4** — Unreal Engine 4，Mordhau 的构建基础。

## 社区 {#community}

**Triternion** — 制作 Mordhau 的工作室。

**决斗服务器** — 为一对一战斗而设置的服务器，通常有不打扰的礼仪规则。

**等级 200** — 等级上限。信号显示的是比赛时间而不是技巧，尽管两者是相关的。
