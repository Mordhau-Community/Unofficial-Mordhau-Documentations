# 支持文档 {#support-the-docs}

该网站是非官方的，由社区运营。它是免费阅读的，没有任何内容
没有广告，没有跟踪器，而且它从不要求您注册帐户。保持这样的状态
方式是重点，也是此页面存在的原因：一个站点
拒绝出卖你的注意力必须以其他方式支付。

## 它去哪里 {#where-it-goes}

一切都是为了让文档保持活力。这就是整个列表。

**保持在线状态。** 域名和托管费用是自掏腰包的。
它们不是大额钞票，但每年都会收到，无论是否有人收到过。
那个月有时间写任何东西。

**保持真实。** Mordhau 发生变化。补丁移动值，重命名配置键，
并悄悄地打破一年前正确的指示。文档
没有人维护的不再是文档并成为陷阱，并且
翻阅旧页面并检查它们是一项缓慢而乏味的工作
与当前版本相比，这是该网站值得一读的主要原因。

**保持宽度。**仍然存在间隙：页面以轮廓存在，而不是
比指南和只翻译了少数页面的语言。
这些都是由人们在上面度过夜晚而填补的。

## 它不去做什么 {#what-it-does-not-go-to}

没有人从中获得薪水，背后没有公司，而且它是
不隶属于 Triternion 或得到他们的认可。如果还有更多的话
钱比网站需要的多，它会去同一个地方：更多的页面，更多的钱
语言，花更多时间检查旧语言。

## 无需付费即可提供帮助 {#helping-without-paying}

金钱并不是网站运营的唯一来源，老实说，这也不是网站的唯一目标。
最稀缺的一个。时间是。

- **修复某些问题。** 如果页面错误、过时或缺少一个步骤
这么说可以节省你一个小时。每个页面都有一个编辑链接
底部。
- **翻译一页。** 英语是最完整的语言，其他语言
跟踪它。除了会说语言之外，这不需要任何技术知识。
- **写下你解决的问题。** 人们解决的尴尬问题
Discord 线程正是从未进入文档的线程。
