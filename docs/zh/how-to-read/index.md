# 如何阅读我们的指南 {#how-to-read-our-guides}

一个关于如何构建此网站的简短页面，以便您可以快速找到内容并了解方框和选项卡的含义。

## 组织方式 {#how-it-is-organised}

顶部栏分为两半。

**信息**是关于该项目的——我们是谁，为什么 Mordhau 需要这个，以及如何做出贡献。

**指南** 是文档本身，并按其用途进行分组。玩家指南涵盖了游戏。开发人员和模组制作者指南涵盖了运行服务器、RCON、SDK 以及出现故障时应采取的措施。

左侧的侧边栏出现在属于系列的页面上，例如贡献部分。如果没有侧边栏，该页面将独立存在。

在右侧，大纲列出了当前页面上的标题。在像服务器指南这样的长页面上，这是跳转到您需要的部分的最快方法。

## 搜索 {#search}

顶部栏中的放大镜，或 <kbd>Ctrl</kbd> + <kbd>K</kbd>，搜索您当前正在阅读的语言的每页全文。如果您知道配置键或命令的名称，请直接搜索。

## 语言 {#languages}

语言图标切换语言。并非所有页面都以每种语言存在 - 英语是最完整的，其他页面在人们翻译时正在填充。如果页面尚未翻译，您将返回英文版本。

填补这些空白之一确实有用，并且 [提供翻译](/zh/contributing/methods)除了会说语言之外，不需要任何技术知识。

## 阅读模式 {#read-mode}

顶栏下方的**阅读模式**按钮隐藏栏、侧边栏和
大纲，只留下文章。再按一次即可将它们带回来。

## 方框的含义 {#what-the-boxes-mean}

彩色面板出现在整个指南中，它们不是装饰 - 颜色告诉您需要注意多少。

::: info
背景。知道很有用，但没有它你也可以继续。
:::

::: tip
建议。通常是捷径，或者我们这样做的方式。
:::

::: warning
阅读此内容。它标记了人们经常犯错的地方。
:::

::: danger
会破坏您的服务器、丢失您的配置或将其暴露给陌生人的东西。不要跳过红色框。
:::

## 代码块 {#code-blocks}

灰色块中的任何内容都应完全按照书写方式键入或粘贴：

```bash
./steamcmd.sh +login anonymous +app_update 629800 validate +quit
```

如果 Windows 和 Linux 上的步骤不同，您将获得选项卡。单击与您的机器匹配的选项卡 - 这些选项卡不是同一指令的两半，它们是写入两次的同一指令。

::: 代码组

```powershell [Windows]
.\MordhauServer.exe
```

```bash [Linux]
./MordhauServer.sh
```

:::

您需要替换的值按其本来面目命名。`RconPassword=a-different-long-password` 表示放你自己的密码在那里，而不是那个文字字符串。

`Inline code` 标记文件名、配置键、命令和路径 - 任何与确切字符相关的内容。

## 遵循指南 {#following-a-guide}

从上到下工作。服务器指南特别建立在自身之上：它安装 SteamCMD，然后下载服务器，然后启动一次以生成配置，然后编辑该配置。跳到配置部分将不起作用，因为该文件尚不存在。

如果某个步骤没有按照页面所述执行，请先检查底部的故障排除部分，然后再假设您做错了。那里的大多数条目之所以存在，是因为它发生在我们当中。

## 当页面错误时 {#when-a-page-is-wrong}

会发生。Mordhau 被修补，主机更改其面板，页面变得陈旧。

如果此处的内容与实际情况不符，请告诉我们。每个页面底部的 **编辑此页面** 链接可以直接在 GitHub 中打开它，或者您可以打开 [问题](https://github.com/Mordhau-Community/Unofficial-Mordhau-Documentations/issues) 或在 [Discord](https://discord.gg/zuX58yRV84) 中说些什么。刚刚遇到问题的人的纠正比我们所能猜测的任何事情都更有价值。
