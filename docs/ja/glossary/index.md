# Glossary {#glossary}

Mordhau のコミュニティ用語、およびこのサイト全体で登場するサーバーおよびモッディング用語。ここまたは Discord で何かを読んだものの、その意味が分からなかった場合は、ここから始めてください。

戦闘用語は [戦闘メカニクス](/ja/combat-mechanics/) で適切に説明されています。これらは短縮版です。

## 戦闘 {#combat}

**アクセル** — スイングに変わり、アニメーションが示唆するよりも早く接続し、パリィを打ち負かします。

**バレリーナ** — 打撃の着地を誤魔化すためにスイング中に激しく回転する人。効果的ですが、広く嫌われています。

**チャンバー** — 入ってくる攻撃を自分の攻撃と同じ角度で迎え、それを逸らし、攻撃を継続します。

**ドラッグ** — パリーの有効期限が切れた後、できるだけ遅く着地するようにスイングから背を向けます。

**フェイント** — ワインドアップ中に攻撃をキャンセルし、相手が何も受け流さないようにします。

**ひるみ** — 攻撃の途中で攻撃を受けて中断される。

**フットワーク** — 武器ではなく動きで距離を管理します。ほぼ全員から過小評価されている。

**ハイパーアーマー** — ひるむことができないフレーム。リポストにはそれがある。

**キック** — 保留されたパリィをブレイクします。遅くて空振りしたら罰が与えられる。

**モーフ** — ワインドアップ中のストライクをスタブに変える、またはその逆。

**オーバーヘッド** — 上から降ってくる攻撃。

**パリィ** — ブロック。右クリック、短いウィンドウ、スタミナを消費します。

**回復** —攻撃後の段階で、行き詰まって脆弱な状態になります。

**リリース** — 武器が実際に誰かにダメージを与える可能性があるフェーズ。

**Riposte** — パリーに成功した後に得られる素早い攻撃。フェイントや変形はできません。

**突き** — 突き。狭くて素早く、隙間にもフィットします。

**スタミナ** — パリー、フェイント、モーフ、ミスの背後にあるリソース。ゼロを打つと武装解除されます。

**ストライク** — 水平方向のスイング。

**カメ** — パリーの後ろに座って決して攻撃しない人。奴らを蹴り飛ばせ。

**空振り** — 攻撃を外しました。スタミナを消費し、回復が残ります。

**ワインドアップ** — 誰かを傷つける前に、武器が後退する段階。

## ゲーム モード {#game-modes}

**BR** — バトル ロイヤル。

**FFA** — すべて無料。全員が全員に対して。

**フロントライン** — キャプチャ ポイントをプッシュし、ウェーブをリスポーンするオブジェクティブ モード。

**Horde** — 協同組合、AI の波。

**侵入** — 攻撃者は防御者に対して一連の目標を達成します。

**スカーミッシュ (SKM)** — リスポーンのないラウンドベースのチーム モード。

**TDM** — チームデスマッチ。

サーバー マップ名はモード プレフィックスとマップを組み合わせているため、`FFA_Grad` は全員無料の卒業生、`TDM_Camp` はチーム デスマッチのキャンプです。

## 装備 {#equipment}

**ロードアウト** — キャラクタービルド。固定ポイントの予算を全体にわたって費やす武器、防具、特典。

**特典** — 装備と同じ予算で購入されたパッシブ特性。特典が増えると防具が減ります。

**ポイント** — ロードアウトの構築に使用される予算。すべてが同じプールをめぐって競合します。

**ツールボックス** — スパイクを構築し、オブジェクトを修復できます。フロントラインではよくあること。

## サーバー {#servers}

**ビーコン ポート** — デフォルトでは UDP 15000。サーバーブラウザがサーバーに到達する方法。それをブロックすると、サーバーは正常に動作し、表示されなくなります。

**ゲーム ポート** — デフォルトでは UDP 7777。実際のゲームプレイのトラフィック。

**クエリ ポート** — デフォルトでは UDP 27015。ブラウザがプレイヤー数とサーバー名を読み取る方法。

**Game.ini** — `Saved/Config/WindowsServer/` または `Saved/Config/LinuxServer/` の下にあるメイン サーバー構成ファイル。

**Engine.ini** — エンジン レベルの設定、特にティック レート。

**MaxSlots** — プレーヤーの容量。

**マップのローテーション** — サーバーが循環するマップのリスト (それぞれ `MapRotation` 行)。

**Playfab ID** — Mordhau が管理コマンドに使用するプレーヤー識別子。Steam IDではありません。`playerlist` で入手してください。

**RCON** — リモート コンソール。ゲームに参加していなくても、ネットワーク経由でサーバーにコマンドを送信します。[RCONガイド](/ja/rcon-guide/)を参照してください。

**SteamCMD** — Valve のコマンド ライン ツール。サーバー ファイルをダウンロードして更新する方法。

**ティック レート** — サーバーがワールドを更新する頻度 (Hz 単位)。高いほどスムーズになり、CPU コストが増加します。

**アプリ629800** — Steam の専用サーバー。ゲーム自体は 629760 であり、この 2 つを混同するのは典型的な最初の間違いです。

## Modding {#modding}

**mod.io** — Mordhau が MOD を配布するために使用するプラットフォーム。

**Mordhau エディタ** — 公式マップおよび MOD 作成ツール、Unreal Engine のビルド。[SDKガイド](/ja/mordhauSDK-guide/)を参照してください。

**SDK** — ソフトウェア開発キット。Mordhau の会話では通常、編集者を意味します。

**UE4** — Unreal Engine 4、Mordhau が構築されているもの。

## コミュニティ {#community}

**Triternion** — Mordhau を制作するスタジオ。

**デュエル サーバー** — 1 対 1 の戦い用にセットアップされたサーバー。通常は中断をしないというエチケット ルールが設けられています。

**ランク 200** — レベルキャップ。スキルではなくプレイ時間を表しますが、この 2 つは相関関係があります。
