# MordhauSDK ガイド {#mordhausdk-guide}

**Mordhau エディタ** は、Mordhau のカスタム マップとゲーム モードを構築するための公式ツールです。これは、Mordhau のアセットとゲーム コードがロードされた Unreal Engine のビルドであるため、それらの近似ではなく、実際の武器、キャラクター、ゲームプレイを操作することになります。

Triternion は、2021 年 12 月 14 日にリリースされました。コミュニティの人々は通常、これを SDK と呼びます。

::: warning
このページは説明用であり、完全なチュートリアルではありません。Mordhau の改造についてはどこにも十分に文書化されていません。まさにこのサイトがそのギャップを埋めるために存在しています。しかし、それを適切に埋めるには、実際にマップを出荷した人が必要です。それがあなたなら、[お問い合わせ](/ja/contributing/methods)。私たちは、誰かが推測して書いた洗練されたページよりも、あなたのラフなメモを公開したいと考えています。
:::

## 作れるもの {#what-you-can-make}

- **マップ** - 既存モードの新しいレベル
- **ゲームモード** - カスタムルールと目標
- **装飾品とアセット** — ゲームに持ち込まれるモデルとマテリアル

Mod は **mod.io** を通じて配布され、ゲーム内の Mod ブラウザーはそこから読み取ります。プレイヤーはそこでサブスクライブし、ゲームがコンテンツをダウンロードします。

## このガイドの内容 {#in-this-guide}

- [アクター](/ja/mordhauSDK-guide/actors) — レベルに配置するもの全般と、どのマップにも必要な Mordhau 固有のアクター：スポーン地点、キャプチャーポイント、押す目標
- [ブループリント](/ja/mordhauSDK-guide/blueprints) — ゲーム側の Blueprint がどう整理されているか、どれをサブクラス化するか、そして特に重要な少数

## 入手方法 {#getting-it}

エディターは **Steam にはありません**。**Epic Games Store** で配布されている無料の別製品で、Epic Games ランチャーからインストールします。

1. [Epic Games Store の MORDHAU Editor ページ](https://store.epicgames.com/p/mordhau--editor)を開き、Epic アカウントでサインインして入手します（無料です）。
2. Epic Games ランチャーを開き、**ライブラリ** にある **MORDHAU Editor** をインストールします。

Steam ではなく Epic にあるのは Triternion の好みではありません。エディターは Unreal Editor のビルドであり、Epic のエンジンライセンスがエディターのビルドを Epic Games Store 経由でしか配布できないと定めているためです。

エディターはゲームとは別に入手するもので、Steam 版の所有状況とは結び付いていません。ただし、作ったものを実際に遊ぶには Mordhau 本体が必要です。エディターには、出発点として使えるサンプルのマップとゲームモードがいくつか同梱されています。

::: warning
古い解説では、Steam ライブラリの **ツール** からエディターを探すように書かれていることがあります。そこには何もありません。Mordhau のエディターは Epic Games Store でのみ配布されています。
:::

::: tip
大きいです。これは完全な Unreal Engine エディターにゲームのアセット ライブラリを加えたものです。ゲーム自体が必要とするよりもかなり多くのディスク容量を割り当て、最初の起動ではシェーダーのコンパイルに長時間かかることが予想されます。これは正常であり、その後は速くなります。
:::

## 始める前に {#before-you-start}

エディターは Unreal Engine です。学習する必要があるほとんどすべては、Mordhau 固有の知識ではなく、一般的な Unreal の知識です。レベル エディター、マテリアル システム、ライティング、ブループリント、およびパッケージ化の仕組みはすべて標準です。

それは良いニュースです。膨大な量の Unreal Engine 資料が世の中にあり、そのほとんどが当てはまります。Mordhau 固有の部分は比較的小さく、ゲームの既存のどのクラスをビルドするか、および mod.io 用にパッケージ化する方法を知っています。

コミュニティ ツールは通常 **Unreal Engine 4.26** を追跡しているため、チュートリアルを探している場合は、UE5 マテリアルよりも UE4 マテリアルの方が、表示されている内容とはるかによく一致します。

これまでに Unreal を開いたことがない場合は、まず一般的な初心者レベルのデザイン チュートリアルに取り組んでください。エンジンを学習し、同時に Mordhau の詳細を学習するのは悪い経験です。

## 大まかなワークフロー {#a-rough-workflow}

マップの作成は大まかに次の手順で行われます。

1. Epic Games Store からエディターをインストールし、最初の起動を完了させます。
2. 新しいレベルを作成するか、付属のマップの 1 つを開いて、それがどのように組み立てられているかを確認します。
3. ジオメトリ、ライティング、[スポーン地点](/ja/mordhauSDK-guide/actors#spawns-mordhauplayerstart)を構築します。
4. サポートしたいモードごとに、[ゲームモード](/ja/mordhauSDK-guide/blueprints)と[目標物](/ja/mordhauSDK-guide/actors)を、モードごとのサブレベルに設定します。
5. ローカルでテストします。
6. パッケージ化して mod.io にアップロードします。
7. [専用サーバー](/ja/dedicated-server-guide/) にロードして、他の人がプレイできるようにします。

公式マップを開くのが、本当に最速で学習できる方法です。これらは、Mordhau レベルがどのように組み立てられるかを説明するための最良のドキュメントです。
