## サーバーの実行 {#running-a-server}

- [LinuxGSM Mordhauの設定](https://github.com/GameServerManagers/Game-Server-Configs/tree/master/Mordhau) — すべてのデフォルト値が含まれる参照 `Game.ini`。設定がどのようなものであるかを確認するのに役立ちます
- [リナックスGSM](https://linuxgsm.com/servers/mhserver/) - Linux サーバーの管理スクリプト、更新と再起動を処理します
- [cm2network/mordhau](https://github.com/CM2Walki/Mordhau) - Docker イメージ (コンテナーで実行したい場合)
- [SteamCMD ドキュメント](https://developer.valvesoftware.com/wiki/SteamCMD) — Valve 独自のリファレンス
- [mcrconの](https://github.com/Tiiffi/mcrcon) — [RCONガイド](/ja/rcon-guide/) で使用される RCON クライアント
- [GPORTAL管理者コマンドリスト](https://www.g-portal.com/wiki/en/mordhau/) — 構文
