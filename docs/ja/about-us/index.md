# 私たちについて {#about-us}

Mordhau ガイドは、ボランティアの貢献者によって作成および維持されているゲーム Mordhau、
の非公式ドキュメント プロジェクトです。

専用サーバーの実行、RCON の使用、または SDK
の操作に必要なもののほとんどは、長年にわたって存在しており、Discord スレッド、フォーラムの投稿、および
の個人メモに散在しています。その素材は簡単に失われます。スレッドがスクロールして手の届かないところに到達し、
サーバーの所有者が再生を停止します。プロジェクトはそれを
の固定順序で 1 か所に収集し、ゲームにパッチが適用されるたびに最新の状態に保ちます。

プロジェクトは独立しています。Triternion とは提携しておらず、
によって承認されておらず、すべてのページは開発者ではなくプレイヤーによって書かれています。

貢献は誰にでも開かれており、役立つもののほとんどは小規模なものです。
の修正、欠落しているステップ、別の言語へのページの翻訳などです。
[貢献方法](/ja/contributing/) はプロセスを設定します。
