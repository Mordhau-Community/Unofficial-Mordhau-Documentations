# Mordhau 不足 {#mordhau-lack}

Mordhau はプレイするゲームとして十分に文書化されていますが、プレイするゲームとしてはほとんど文書化されていません。
走る。サーバーへの参加以降のすべて - サーバーのホスト、管理、構築
それについて、または壊れた場合にそれを修正することについては、公式のリファレンスが維持されていません。

## どこにギャップがあるのか {#where-the-gaps-are}

**専用サーバー。** SteamCMD を通じてインストール、`Game.ini` の形状、
どのポートを開く必要があるか、それぞれのポートが何のためにあるか、すべてが必要です。
頻繁に意見が相違するフォーラムのスレッドから再構築されたものです。

**RCON.** プロトコルは機能し、コマンドは存在しますが、
それらの信頼できるリスト、どれが変更されたかの記録はなく、
名前が何をするのか説明していないものの説明。

**SDK.** エディターを開くのに十分なものが見つかります。完成して出荷するのに十分な量
作業マップや MOD はほとんどが口頭伝承です。

**エラー。** 失敗メッセージは簡潔であり、原因が明らかになることはほとんどありません。
ほとんどの答えは、ある人に対して一度書かれた Discord 返信の中に存在します。
人。

## なぜそのままなのか {#why-it-stays-that-way}

通常、小さなスタジオが最初に作成するのはドキュメントであり、最後に作成するものです。
コミュニティが拾ったもの。書くのは遅いし、決して終わらないし、
値を移動したりキーの名前を変更したりするパッチはすべて、その一部を最新のものにしません。
また。

しかし、知識は消えませんでした。それは決して書き留められなかっただけです
どこでも耐久性があります。スクロールして手の届かないスレッドやフォーラムに生息しています。
それ以来静かになりましたが、それを解決したサーバー所有者の記憶の中にあります。
試行錯誤して、ずっと前にプレイをやめてしまいました。彼らが去れば、彼らも去ります
彼らと一緒に。

## それにかかる費用は {#what-that-costs}

何かを実行したり構築したりしたい人にとっては、高額な参加費がかかります。同じ
数週間ごとに質問にゼロから回答します。サーバーが誤って構成されたままになっている
なぜなら、正しい設定がどこにも書かれていなかったからです。そして
面白いはずだった部分に到達する前に諦めてしまう人。
