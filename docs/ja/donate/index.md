# ドキュメントをサポートする {#support-the-docs}

このサイトは非公式であり、コミュニティによって運営されています。無料で読めますが、内容はありません
広告やトラッカーはなく、アカウントの作成を求められることもありません。それを維持する
方法こそが重要であり、このページが存在する理由でもあります。
あなたの注意を引くことを拒否した場合は、別の方法で注意を払う必要があります。

## どこへ行くのか {#where-it-goes}

すべてはドキュメントを存続させるために行われます。それがリスト全体です。

**オンラインを維持します。** ドメインとホスティングの料金は自腹で支払われます。
高額な請求書ではありませんが、誰かが持っているかどうかに関係なく、毎年届きます。
その月は何かを書く時期です。

**真実を維持します。** Mordhau は変更されます。パッチは値を移動し、設定キーの名前を変更します。
そして1年前には正しかった指示を静かに破ります。ドキュメント
誰も維持していないものは文書ではなくなり、罠になります。
古いページを遡ってチェックするという、ゆっくりとした地味な作業
現在のビルドとの比較こそが、このサイトを読む価値のあるものにしているのです。

**幅を広く保ちます。** まだギャップがあります: ページはアウトラインとして存在します。
ガイドや数ページしか翻訳されていない言語よりも。
それらは人々が夜を過ごすことで埋められます。

## 進まないもの {#what-it-does-not-go-to}

このことから誰も給与が支払われず、背後に会社もありません。
Triternion と提携していないか、または彼らによって承認されていません。これ以上あるなら
サイトが必要とする以上のお金が同じ場所に送られます: ページが増えれば増えるほど
言語を変更すると、古い言語のチェックにさらに時間がかかります。

## お金を払わずに手助けする {#helping-without-paying}

サイトを運営するのはお金だけではありません。正直に言うと、お金だけがお金ではありません。
最も希少なもの。時間は。

- **何かを修正してください。** ページが間違っている、古い、または 1 つの手順が欠けている場合
そうすれば一時間は節約できるでしょう、そう言ってください。すべてのページには編集リンクがあります。
一番下。
- **ページを翻訳します。** 英語は最も完全な言語であり、その他の言語です
それを追跡します。これには、言語を話す以外の技術的な知識は必要ありません。
- **解決したことを書き留めてください。** 人々が解決する厄介な問題
Discord スレッドは、まさに文書化されないスレッドです。

[貢献方法](/ja/contributing/) では、次の 3 つすべてを説明します。
これまで Git に触れたことがない場合は、セットアップを行ってください。
