# 解決策とエラー {#solutions-and-errors}

よく起こる問題と、通常はそれを解決するもの。ほとんどの質問はそこから来ているため、最初にサーバーの問題が考えられます。

::: tip
何よりもまずログを読んでください。ほとんどの場合、何が間違っているかを正確に示します。

- **サーバー:** サーバーインストール内の `Mordhau/Saved/Logs/`
- **クライアント (Windows):** `%LOCALAPPDATA%\Mordhau\Saved\Logs\`

`-log` でサーバーを起動すると、その処理がコンソールに出力されます。これは、事後的にファイルを読み取るよりもはるかに簡単です。
:::

## サーバーの問題 {#server-problems}

### サーバーがブラウザに表示されない {#the-server-does-not-appear-in-the-browser}

これまでで最も一般的なポートであり、ほとんどの場合、**ビーコンまたはクエリ ポート**です。

ゲームポートを通過させるだけでは十分ではありません。3 つの UDP ポートはすべて開いて転送する必要があります。

|ポート |プロトコル |ブロックされた場合の結果 |
| --- | --- | --- |
|7777 |UDP |誰も接続できません |
|15000 |UDP |サーバーがブラウザに表示されない |
|27015 |UDP |サーバーが表示されないか、情報なしで表示されます。

次の順序で作業してください。

1. サーバーは実際に稼働していますか?コンソール出力を確認します。
2. マシン自体のファイアウォールがそれを許可していますか?Windows ファイアウォールは初回起動時にサーバーをブロックしますが、プロンプトは読まずに簡単に閉じることができます。
3. ルーター上の 3 つのポートはすべて **UDP** として正しい内部 IP に転送されていますか?
4. マシンのローカル IP は変更されましたか?DHCP はアドレスを再割り当てし、転送ルールは何もポイントしません。サーバーに静的ローカル IP または DHCP 予約を与えます。

自分のネットワークでは機能するが外部からは機能せず、転送が間違いなく正しい場合は、ISP が CGNAT の背後に置いている可能性があります。それを介してホストすることはできません。また、構成をいくら変更しても変更されません。VPS が必要です。

### 設定を変更しても何も起こりません {#config-changes-do-nothing}

サーバーの実行中に `Game.ini` を編集しました。

Mordhau はその構成をメモリ内に保持し、シャットダウン時にそれを書き戻し、起動時にロードした内容でファイルを上書きします。サーバーを停止し、編集してから起動します。

### サーバーが起動してもすぐに終了してしまう {#the-server-closes-immediately-after-starting}

ログを読んでください。通常、次のいずれかです。

- **ポートはすでに使用されています。** 別のサーバー、または終了していない前のインスタンス。浮遊プロセスがないか確認するか、別のポートに移動してください。
- **ファイルが見つかりません。** 最後に `validate` を指定して、SteamCMD コマンドを再実行します。
- **不正な形式の `Game.ini`.** セクション ヘッダーのタイプミス、または数値が予期されていた値です。

### 誰も接続できないが、サーバーはリストに表示される {#nobody-can-connect-but-the-server-is-listed}

ゲームポート、7777 UDP。上記と同じチェック。

リストに表示され、接続は開始されるがすぐに切断される場合は、`ServerPassword` が忘れた値に設定されているかどうかを確認してください。

### 管理コマンドが拒否される {#admin-commands-are-rejected}

最初に `adminlogin` と `AdminPassword` のパスワードを入力します。それ以前は何も機能しません。

それでも拒否される場合は、サーバーの実行中にパスワードを編集したために上書きされてしまいます。上記を参照してください。

### RCONが接続できない {#rcon-will-not-connect}

**接続が拒否されました** — RCON がリッスンしていません。`RconPort` を `Game.ini` に設定し、サーバーを再起動する必要があります。

**接続タイムアウト** - ファイアウォール。RCON ポートは他の 3 つとは異なり **TCP** であるため、ゲーム ポートをカバーするルールはカバーされないことに注意してください。

**認証に失敗しました** - パスワードが間違っています。`RconPassword` を空白のままにすると、サーバーは起動時にランダムな値を生成しますが、それを知る方法はありません。明示的に設定して再起動してください。

[RCONページ](/ja/rcon-guide/) の詳細。

### サーバーは古いビルドを実行しています {#the-server-is-running-an-old-build}

Mordhau クライアントは、異なるバージョンのサーバーに参加できません。パッチを適用した後、次を再実行します。

```bash
./steamcmd.sh +force_install_dir ~/mordhau-server +login anonymous +app_update 629800 validate +quit
```

`+force_install_dir` は `+login` より前に指定する必要があります。そうでない場合、SteamCMD はそれを無視し、間違ったフォルダーを更新します。

### サーバーがいっぱいだとパフォーマンスが悪い {#performance-is-bad-with-a-full-server}

`Engine.ini` の `NetServerMaxTickRate` を確認してください。ハードウェアが耐えられる値よりも高く設定すると、サーバーが遅れをとり、全員がラバーバンディング状態になります。安定した 60 は、不安定な 120 よりもはるかに良いと感じます。

Mordhau は主にシングルスレッドに依存しているため、コア数よりもシングルコアのクロック速度が重要です。低速コアを多数搭載した安価な VPS は適していません。

## クライアントの問題 {#client-problems}

::: info
ここではほとんどの人がクライアントをサポートするのではなくサーバーを実行しているため、このセクションはサーバーのセクションよりも薄いです。リストされていないものを修正した場合は、[追加する](/ja/contributing/methods)。
:::

### ゲームが始まらない {#the-game-will-not-start}

1. Steam を通じてゲーム ファイルを確認します。Mordhau を右クリックし、[プロパティ]、[インストールされたファイル]、[整合性の確認] の順にクリックします。
2. グラフィックドライバーを更新してください。
3. リブート。実際、チート対策の問題については、これにより必要以上に頻繁に問題が修正されます。

### アンチチートエラー {#anti-cheat-errors}

Mordhau は Easy Anti-Cheat を使用しており、ほとんどの起動エラーはこれに遡ります。

- ゲームフォルダー内の EAC インストーラーを再度実行します。
- Steam を管理者として起動してみてください。
- ウイルス対策ソフトがゲームまたは EAC を隔離していないことを確認してください。セキュリティ ソフトウェアがアンチチートをマルウェアと間違えるのは、動作が似ているためよくあります。

### 試合中に接続が切れた {#disconnected-during-a-match}

- 特定の 1 つのサーバーの場合、それはあなたではなく、そのサーバーです。
- すべてのサーバーの場合は、一般的に接続をテストします。Wi-Fi が原因となることがよくあります。可能であればケーブルを試してください。
- パケット損失はラバーバンディングとして現れ、切断として現れる前に記録されないヒットが発生します。

### フレームレートが悪い {#poor-frame-rate}

影を低くし、距離を第一に考えると、視覚的な違いを最小限に抑えるために最もコストがかかります。サーバーがフルのフロントラインはゲームの最悪のケースです。そこでのみ途切れる場合、それは負荷であり、障害ではありません。
