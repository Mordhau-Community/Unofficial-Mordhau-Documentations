# Mordhau ゲーム {#mordhau-game}

Mordhau は、臨場感あふれる戦闘システムで
プレイヤーを魅了したマルチプレイヤー中世ハックアンドスラッシュ ゲームです。見事なビジュアルと戦略的な
ゲームプレイ。Triternion によって開発された Mordhau は、プレイヤーに
の激しい近接戦闘に参加し、キャラクターをカスタマイズし、大規模な戦闘、決闘、協力ミッションなどのさまざまな
ゲーム モードを探索する機会を提供します。

2019 年のリリース以来、このゲームはプレイヤー
と、カスタム
サーバー、MOD、およびゲームプレイの改善を通じてエクスペリエンスを向上させることに情熱を注ぐモッダーの専用コミュニティを構築してきました。

実際の戦闘方法については、[戦闘の整備士](/ja/combat-mechanics/)を参照してください。
ゲームに記載されていない内容については、[Mordhau ラック](/ja/mordhau-lack/) を参照してください。
