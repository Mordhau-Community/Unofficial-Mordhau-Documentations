# ガイドの読み方 {#how-to-read-our-guides}

このサイトがどのようにまとめられているかについての短いページです。これにより、項目をすぐに見つけ、ボックスやタブの意味を知ることができます。

## 構成方法 {#how-it-is-organised}

上部のバーは 2 つの半分に分かれています。

**情報** はプロジェクトに関するものです。私たちが誰であるか、Mordhau がこれを必要とする理由、および貢献方法です。

**ガイド** はドキュメント自体であり、対象者ごとにグループ化されています。プレーヤーガイドではゲームについて説明します。開発者およびモッダーのガイドでは、サーバーの実行、RCON、SDK、および何かが壊れた場合の対処方法について説明します。

左側のサイドバーは、寄稿セクションなど、シリーズに属するページに表示されます。サイドバーがない場合、ページは独立して表示されます。

右側のアウトラインには、現在のページの見出しがリストされています。サーバーガイドのような長いページでは、これが必要な部分にジャンプする最も速い方法です。

## 検索 {#search}

上部バーの虫眼鏡、または <kbd>Ctrl</kbd> + <kbd>K</kbd> を検索します。現在読んでいる言語の各ページの全文。構成キーまたはコマンドの名前がわかっている場合は、それを直接検索してください。

## 言語 {#languages}

言語アイコンは言語を切り替えます。まだすべてのページがすべての言語で存在しているわけではありません。英語が最も完全であり、他のページは人々が翻訳しながら埋められています。ページが翻訳されていない場合は、英語版に戻ります。

これらのギャップの 1 つを埋めることは非常に便利であり、[翻訳に貢献](/ja/contributing/methods)言語を話すこと以外の技術的な知識は必要ありません。

## 読み取りモード {#read-mode}

トップバーの下にある **読み取りモード** ボタンは、バー、サイドバー、および
アウトラインを非表示にし、記事だけを残します。もう一度押すと元に戻ります。

## ボックスの意味 {#what-the-boxes-mean}

ガイド全体に色付きのパネルが表示されますが、それらは装飾ではありません。色は、どれだけ注意を払うべきかを示します。

::: info
背景。知っておくと便利ですが、知らなくても続行できます。
:::

::: tip
アドバイス。通常、ショートカット、または私たちが行う方法です。
:::

::: warning
これを読んでください。人々がよく間違える場所を示しています。
:::

::: danger
サーバーを破壊したり、設定を失ったり、見知らぬ人に公開したりするもの。赤いボックスを読み飛ばさないでください。
:::

## コード ブロック {#code-blocks}

灰色のブロック内の内容は、書かれたとおりに入力または貼り付けられることを意味します:

```bash
./steamcmd.sh +login anonymous +app_update 629800 validate +quit
```

Windows と Linux でステップが異なる場合、タブが表示されます。ご使用のマシンに一致するものをクリックしてください。タブは同じ命令を半分に分けたものではなく、同じ命令が 2 回書かれたものです。

::: コードグループ

```powershell [Windows]
.\MordhauServer.exe
```

```bash [Linux]
./MordhauServer.sh
```

:::

置換する必要がある値には、その内容に応じた名前が付けられています。`RconPassword=a-different-long-password` は自分のものを置くことを意味しますリテラル文字列ではなく、パスワードがそこにあります。

`Inline code` は、ファイル名、構成キー、コマンド、パスなど、正確な文字が重要なあらゆるものをマークします。

## ガイドに従って {#following-a-guide}

上から下に作業します。特にサーバー ガイドはそれ自体で構築されています。SteamCMD をインストールし、サーバーをダウンロードし、サーバーを一度起動して構成を生成し、その構成を編集します。ファイルがまだ存在しないため、config セクションにスキップしても機能しません。

手順がページに記載されているとおりに動作しない場合は、手順が間違っていたと考える前に、下部にあるトラブルシューティング セクションを確認してください。そこにあるエントリのほとんどは、それが私たちの一人に起こったために存在しています。

## ページが間違っている場合 {#when-a-page-is-wrong}

ということが起こります。Mordhau にパッチが適用され、ホストのパネルが変更され、ページが古くなります。

ここに記載されている内容が現実と一致しない場合は、お知らせください。各ページの下部にある [**このページを編集**] リンクをクリックすると、GitHub で直接ページを開くことができます。または、[ニュース](https://github.com/Mordhau-Community/Unofficial-Mordhau-Documentations/issues) を開くか、[Discord](https://discord.gg/zuX58yRV84) で何かを入力することもできます。問題にぶつかったばかりの人からの修正は、私たちが推測できるどんなものよりも価値があります。
