# GitHubとは何ですか? {#what-is-github}

GitHub は、Git リポジトリをホストする Web サイトです。プロジェクトがオンラインに保存されるため、全員が同じコピーに対して作業できるほか、問題追跡、コード レビュー、プル リクエストなど、Git 自体が意見を持たない機能も追加されます。

このサイトのソースは [Mordhauコミュニティ/非公式Mordhauドキュメント](https://github.com/Mordhau-Community/Unofficial-Mordhau-Documentations) にあります。ここで読むすべてのページは、そのリポジトリ内の Markdown ファイルです。

Git と GitHub の違いがまだ明確でない場合は、まず [Gitとは?](/ja/contributing/git) をお読みください。

## アカウントの取得 {#getting-an-account}

無料。電子メール アドレスとユーザー名を使用して [github.com](https://github.com) にサインアップします。ユーザー名は公開され、投稿したものすべてに表示されるため、知られてうれしいものを選択してください。

設定中に 2 要素認証をオンにします。いずれにせよ、GitHub は投稿者にそれを必要とします。

## フォーク、ブランチ、プルリクエスト {#fork-branch-pull-request}

これはサイト全体が実行されるワークフローであり、GitHub のどこでも同じです。

### 1.フォーク {#1-fork}

メイン リポジトリに直接プッシュする権限がありませんが、これは意図的なものです。**フォーク** をクリックすると、自分のアカウントで自分の完全なコピーが得られ、好きなように操作できます。

### 2. 変更を加えます {#2-make-your-changes}

ブラウザ内で、またはフォークのクローンを作成してローカルで作業します。`main` に直接置くのではなく、枝に置きます。

### 3. プルリクエストを開く {#3-open-a-pull-request}

プル リクエストは、変更を元のリポジトリにプルするリクエストです。GitHub は、変更内容を 1 行ずつ正確に表示し、何かがマージされる前に全員がそれについて話し合う場を提供します。

何を変更したか、そしてその理由を説明します。問題が修正された場合は、問題番号を記載してください。`Fixes #42` と記述すると、プル リクエストがマージされると、その問題は自動的に閉じられます。

### 4. レビューに返信する {#4-respond-to-review}

誰かが読んでくれるでしょう。彼らは変更を要求するかもしれません。別のコミットを同じブランチにプッシュすると、プル リクエストが自動的に更新されます。新しいコミットを開く必要はありません。

承認されてマージされると、Netlify がサイトを再構築し、変更は数分以内に反映されます。

## それを一切使わずに編集すると、 {#editing-without-any-of-that}

タイプミスの場合は、何もフォークする必要はありません。ここの各ページの下部には [**このページを編集**] リンクがあります。その正確なファイル上で GitHub のエディターが開き、保存すると、GitHub がサイレントにフォークとプル リクエストを実行します。

## 問題 {#issues}

[問題トラッカー](https://github.com/Mordhau-Community/Unofficial-Mordhau-Documentations/issues) は、問題が報告され、作業が計画される場所です。何か問題を見つけて自分で修正する予定がない場合、存在しないページを提案したい場合、またはアイデアに時間を費やす前に実行する価値があるかどうかわからない場合は、ページを開いてください。

まず既存の問題を検索します。すでに誰かが上げているかもしれません。

## リポジトリを監視する {#watching-the-repository}

リポジトリの上部にある **Watch** ボタンをクリックすると、問題が発生したときにメールで通知されます。通常、支援したいがコミットごとに通知を受け取りたくない場合は、**カスタム → 問題** が適切な設定です。

## もっと詳しく知る {#learning-more}

GitHub 独自の [クイックスタート](https://docs.github.com/en/get-started/quickstart) は非常に優れており、所要時間は約 15 分です。GitHub Skills には、実際のプル リクエストを開く手順を説明する無料の [GitHubの紹介](https://github.com/skills/introduction-to-github) コースもあります。
