# Markdownとは {#what-is-markdown}

Markdown は、シンプルかつ効率的な方法でテキストをフォーマットするために使用される軽量のマークアップ言語です。これは、プレーン テキスト ドキュメントを視覚的に魅力的にし、HTML などの構造化フォーマットに簡単に変換できるようにすることを目的として、John Gruber と Aaron Swartz によって 2004 年に作成されました。Markdown は、GitHub のようなドキュメント、ブログ、電子メール、コード リポジトリで広く使用されています。

このマークアップ言語は、ゲーム Mordhau、その開発、またはその MOD の作成とは何の関係もありません。それは単に独立して存在し、さまざまな領域にわたって複数の用途がある知識の分野です。私たちがここでそれを説明しているのは、あなたがこのページを読んでいるゲーム Mordhau のドキュメントに貢献するためにそれを使用しているという理由だけです。

## Markdown はどこで使用されますか? {#where-is-markdown-used}

Markdown は、そのシンプルさと汎用性により、さまざまなコンテキストで使用されます。Markdown が適用される一般的な領域をいくつか示します。

1. **技術ドキュメント:**<br> Markdown は、GitHub、GitLab、Bitbucket などのリポジトリに README ファイルを記述するために広く使用されています。
2. **ブログ プラットフォーム:**<br> Medium や Jekyll などの多くのプラットフォームは、整形式の投稿を簡単に作成するために Markdown をサポートしています。
3. **コンテンツ管理システム (CMS):**<br> Markdown は、Hugo や Gatsby などの静的サイト ジェネレーターでよく使用されます。
4. **電子メールとメッセージング:**<br> Markdown は、特に Slack や Discord などのツールで、クリーンでプロフェッショナルな電子メールやチャット メッセージの書式設定に役立ちます。
5. **メモ作成アプリケーション:**<br> Notion、Obsidian、Evernote などの人気ツールは、メモを効率的に整理するために Markdown をサポートしています。
6. **教育プラットフォーム:**<br> Markdown は、すっきりとした構造化された情報を提示するために Wiki やチュートリアルで使用されます。

## Markdown はどのように機能しますか? {#how-does-markdown-work}

Markdown は、特殊文字を含むプレーン テキスト構文を使用して書式設定を定義します。以下にいくつかの例を示します。

### 1- 見出し: {#1-headings}

```md
# Heading 1

## Heading 2

### Heading 3
```

見出しは、1 ～ 6 文字の `#` 文字で始まる行です。1 つの `#` はページ タイトル、`##` はセクション、`###` はサブセクションです。その後に空行を入れてください。

### 2- 強調: {#2-emphasis}

```md
*italic* or _italic_
**bold** or __bold__
***bold italic***
~~struck through~~
```

### 3- リスト: {#3-lists}

```md
- first item
- second item
  - a nested item, indented by two spaces

1. numbered
2. list
3. of things
```

番号付きリストは自動的に番号を付け直すため、各行に `1.` と記述しても、Markdown は正しくカウントされます。

### 4- リンク: {#4-links}

```md
[text people click](https://example.com)
```

### 5- 画像: {#5-images}

```md
![description of the image](/path/to/image.webp)
```

角括弧内の説明は、スクリーン リーダーが通知する内容と、画像の読み込みに失敗した場合に表示する内容なので、そこに実際の内容を記述します。

### 6- コード: {#6-code}

いくつかの単語を 1 つのバッククォートで囲んでコードとしてマークします。これは、ファイル名、コマンド、構成キーに役立ちます。それ以上の場合は、3 つのバッククォートを使用して言語に名前を付けます。

````md
```bash
ノード -v
```
````

### 7- 引用: {#7-quotes}

```md
> Anything after a > is a quote block.
```

### 8- テーブル: {#8-tables}

```md
| Setting | Meaning |
| --- | --- |
| MaxSlots | How many players fit on the server |
| ServerName | The name shown in the browser |
```

2 行目のダッシュは、それを表に変えるものです。列はソース内で一直線に並んでいる必要はありません。

## Markdown がしないこと {#what-markdown-does-not-do}

Markdown には、色、フォント、テキストの配置、レイアウトに関する構文が意図的にありません。それが重要です。ドキュメントはその構造を説明し、サイトが構造の見た目を決定します。それと戦っていることに気付いた場合は、通常、代わりにテーマが処理すべき何かを行おうとしています。
