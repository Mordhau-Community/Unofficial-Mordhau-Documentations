# その他のリソース {#more-resources}

以下はすべて外部のものです。これらはすべて、ここにコピーするよりもよく管理されているため、再説明するのではなくリンクします。

## Markdown {#markdown}

- [CommonMark リファレンス](https://commonmark.org/help/) — ライブ エディターを使用した 1 ページ上の構文全体
- [Markdownの特長 ガイド](https://www.markdownguide.org/basic-syntax/) —同じ根拠で、さらに詳しく説明
- [VitePress Markdownの特長 エクステンション](https://vitepress.dev/guide/markdown) — このサイトでのみ機能する追加機能

## Git {#git}

- [プロギット](https://git-scm.com/book/en/v2) — 公式書籍、無料オンライン。第 1 章から第 3 章までは、寄稿者が必要とするすべての内容をカバーしています
- [オ・シット!](https://ohshitgit.com/) — たった今間違えた特定のことを元に戻す方法
- [ジット・ブランチングを学ぶ](https://learngitbranching.js.org/) — インタラクティブなビジュアライザー、ブランチを理解するための真の最速の方法
- [git-scm リファレンス](https://git-scm.com/docs) — すべてのコマンドとすべてのフラグ

- [SSHでGitHubに接続する](https://docs.github.com/en/authentication/connecting-to-github-with-ssh)

## VitePress {#vitepress}
