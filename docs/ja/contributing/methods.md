# 貢献方法 {#contribution-methods}

ここで役立つ方法は複数ありますが、そのすべてにリポジトリのクローン作成が含まれるわけではありません。自分が費やしたいと思う時間に合わせて選択してください。

## 1. 問題をオープンする {#1-open-an-issue}

最も労力がかからないオプションですが、正直言って、何か問題を見つけたときに最も役立つオプションです。もう機能しないコマンドを見つけましたか?デッドリンク?矛盾したページですか？[ニュース](https://github.com/Mordhau-Community/Unofficial-Mordhau-Documentations/issues) を開いて説明します。

良い問題には、あなたがどのページにいたのか、何を期待していたのか、そして実際に何が起こったのかが記載されています。修正方法を知る必要はありません。

## 2. ブラウザからページを編集する {#2-edit-a-page-from-the-browser}

このサイトのすべてのページの下部に [**このページを編集**] リンクがあります。それをクリックすると、その正確なファイルが GitHub のエディターで開きます。変更を加え、それを説明する短いメモを書くと、GitHub がリポジトリをフォークし、プル リクエストをオープンします。

これは、タイプミス、リンク切れ、読みにくい文章、または小さな追加の場合に適切な選択です。ターミナルもインストールも設定も何もありません。

## 3. ローカルで作業する {#3-work-locally}

複数のファイルを変更したり、ページを追加したり、サイドバーに触れたりしたら、送信する前に結果を確認できるように、マシン上でプロジェクトをセットアップする価値があります。[導入事例](/ja/contributing/) は、クローンと開発サーバーを経由します。

次の場合はローカルで作業します。

- 新しいページ全体を追加する
- セクションを再構築する
- `.vitepress/config.mts` でナビゲーションを編集する
- 画像の追加

## 4. 翻訳 {#4-translate}

このサイトはすでに英語、アラビア語、フランス語、日本語、ロシア語、中国語で運営されていますが、翻訳されたフォルダーのほとんどは英語のものよりはるかに遅れています。実際に話す言語でページに記入することは、ここでできる最も価値のあることの 1 つです。

翻訳は `docs/<language>/` に存在し、英語の構造を反映しています。英語ファイルを言語フォルダー内の一致するパスにコピーし、本文を翻訳します。フロントマター キーはそのままにして、値のみを変換します。

::: warning
機械翻訳されたページを送信しないでください。その言語を話す人が書いたラフなページは、専門用語を間違えている流暢に見えるページよりも優れています。誰も読んだことのない言語をレビューする方法はありません。
:::

## 5. すでに知っていることを共有する {#5-share-what-you-already-know}

Mordhau の知識の多くは、Discord スレッドや古いフォーラムの投稿にあります。何年もサーバーを実行している場合、または SDK についてどこにも書かれていないことを理解している場合は、それを自分で洗練されたページに変える必要はありません。[Discord](https://discord.gg/zuX58yRV84) にドロップするか、問題に貼り付けると、誰かが形を整えるのを手伝ってくれます。

このプロジェクトの目的の半分は、それを知っている人々が先に進む前に、物事を収集することです。
