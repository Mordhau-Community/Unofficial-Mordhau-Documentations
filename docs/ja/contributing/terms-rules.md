# 投稿規約とルール {#contribution-terms-rules}

ここでは複雑なことは何もありません。これは主に、プル リクエストをレビューしている人が質問する手間を省くためのリストです。

##  {#writing}

の書き方 **これまでにこれをやったことがない人向けに書きます。** このプロジェクトが存在する理由は、既存の Mordhau ドキュメントが、読者がすでに答えを知っていることを前提としているためです。ステップに前提条件が必要な場合は、そのように指定します。

**具体的に指定してください。** 「構成ファイルの編集」は役に立ちません。「`Mordhau/Saved/Config/LinuxServer/Game.ini`を開く」です。

**確信がない場合は言ってください。** 値がテストされていないというメモは、自信を持って間違った数値よりもはるかに優れています。誰かが来てそれを確認します。

**既存の構造を維持します。** セクションにすでにパターンがある場合は、ページ上に新しいパターンを作成するのではなく、そのパターンに従ってください。

## 精度 {#accuracy}

書いた内容をテストします。コマンドを文書化している場合は、それを実行します。構成キーを文書化する場合は、それを実際の `Game.ini` に入れてサーバーを起動します。

他の場所 (別のサイト、Discord メッセージ、ホスティング プロバイダーのナレッジ ベース) から情報を入手した場合は、その情報にリンクします。どちらも、読者がさらに深く掘り下げることができるためと、次の人がそれがどれほど古いかを知ることができるためです。

ゲームの更新によりドキュメントが中断されます。ゲームと一致しなくなった内容を説明しているページに気付いた場合、それを修正することは貢献としてカウントされます。

## コンテンツ {#content}

- 他のサイトからテキストをコピーして貼り付けないでください。リンクするか、自分の言葉で書いてください。
- チート、エクスプロイト、またはゲームの利用規約に違反するものは一切禁止します。
- 広告はありません。サーバー プロバイダーのリストは、誰かがスロットに料金を支払ったからではなく、コミュニティがそれらのホストを使用しているために存在します。
- スクリーンショットは大歓迎です。アップロードする前に個人的なものを切り取ってください。

## プル リクエスト {#pull-requests}

1 つのプル リクエストを 1 つのトピックに保持します。タイプミスを修正し、RCON ページを書き換える PR は、レビューするのが難しく、元に戻すのが困難です。

何が変わったかを示すタイトルを付けてください。「更新」はレビュー担当者に何も伝えません。

送信する前に、ローカルでサイトを実行します。

```bash
npm run docs:dev
```

ページがレンダリングされ、リンクが想定どおりの場所に移動し、他に問題がないことを確認します。

レビューに変更リクエストが返された場合、それは拒否ではありません。別のコミットを同じブランチにプッシュすると、プル リクエスト自体が更新されます。

## 行動 {#behaviour}

礼儀正しくしてください。ここの人々はボランティアで、自由時間にゲームのドキュメントを書いていますが、多くの場合、母国語ではない言語を使用しています。人ではなく内容を修正してください。

## ライセンス {#licence}

あなたが書いた内容の著作権はあなたに保持されます。貢献することで、[CC BY-SA 4.0の特長](https://creativecommons.org/licenses/by-sa/4.0/) の下でこのプロジェクトと他の全員にライセンスを付与し、あなたのクレジットがコミット履歴に記録されます。

公開する権利のないものは投稿しないでください。
