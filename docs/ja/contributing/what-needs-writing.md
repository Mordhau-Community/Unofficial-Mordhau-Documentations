# まだ書く必要があること {#what-still-needs-writing}

ギャップの正直なリストなので、役に立つことを探している人は誰でもそれを行うことができます。
推測する代わりに 1 つを選択してください。

残っていることのほとんどは書くことではありません。それは測定です。測定する必要がある数値です。
ゲームを開いている人によってゲーム内でテストされます。
誰もパッチを発明すべきではありません。テストを実行できれば、
距離を縮めることができる人。

::: tip
始める前に、[精度ルール](/ja/contributing/terms-rules) で次のことをカバーしてください。
ここで最も重要なことの 1 つは、確認できなかったものにはマークを付けることです。
信頼できる数値に四捨五入するよりも。
:::

## プレイヤーガイド {#player-guides}

**武器番号。** [武器とロードアウト](/ja/weapons/) には、武器の選択方法が記載されています。
武器を持ち、統計表を意図的に持ちません。タイプ別ダメージ、ワインドアップ、
リリースタイミング、ポイントコストはすべて欠落しています。これは単一で最大です
現場の隙間。

**アーマー。** 各ティアのコスト、重量、およびそれに対する動作について
それぞれのダメージタイプ。現在、武器ページ内の 1 つの段落です。

**特典** まったく参考になりません。それぞれが何をするのか、それにかかる費用はいくらなのか、
そのために手放す鎧の価値があるかどうか。

**マップ。** サーバー ガイドのローテーション リストにある名前以外のものはありません。レイアウト、
マップごと、モードごとの目標とコールアウト。

**進行状況** レベル、ゴールド、いつロック解除されるもの。

## サーバーガイド {#server-guides}

**管理コマンド。** [RCONガイド](/ja/rcon-guide/) には、管理コマンドが含まれています。
実行するタスクのニーズ。利用可能なものの完全なリファレンス、
そして、それぞれが実際に何をするかはまだ存在しません。

**MOD のホスティング** MOD を追加したサーバーを実行する方法と、実行すると何が壊れるのか。

**パフォーマンス。** サーバー ガイドはティック レートに触れます。その他すべてについて
最大のプレイヤー数でスムーズなサーバーを実行することは文書化されていません。

## 翻訳 {#translations}

アラビア語、フランス語、日本語、ロシア語、中国語はそれぞれ数ページあります
英語セクションの2ダースに対して。翻訳されたページには技術は必要ありません
言語を話すことを超えた知識、そして
[貢献方法](/ja/contributing/methods) では、言語の仕組みについて説明します。
フォルダーは機能します。

機械翻訳はしないでください。を話す人による大まかなページ
専門用語を間違う流暢な言語よりも、言語の方が価値があります。

## 完成したものはこんな感じ {#what-finished-looks-like}

ページは、そのことをやったことがない人がそれをフォローし始めたときに完了します。
他に何も開かずに終了し、そこにあるすべての番号が来たら
テストからのものであるか、未テストとしてマークされています。

これは、ここにすでに存在するもののほとんどよりも高いハードルです。ページは次のように改善されます
修正中であるため、ギャップについて正直に述べた最初の草稿にははるかに価値があります
全く何もないよりは。
