# Dedicated Game Server Providers

If you would rather not run [your own server](/en/dedicated-server-guide/), these companies rent Mordhau servers with a web control panel. You pay per slot per month, they handle the machine, the updates and the ports, and you get a config editor and a console in a browser.

The hosts below are the ones the Mordhau community has used over the years.

::: info
We are not affiliated with any of them and none of these are affiliate links. Prices, regions and quality change over time — shop around, and ask in the [Discord](https://discord.gg/zuX58yRV84) how a host is doing lately before you commit to a long rental.
:::

## Choosing one

A few things worth checking before you pay for six months up front:

**Where the hardware is.** Ping is the thing your players will notice first. Pick a location near the people you expect to play with, not near you.

**Whether you get file access.** Some panels only expose a handful of settings through a form. If you want to properly edit `Game.ini` and `Engine.ini` you want FTP or a real file manager.

**Whether RCON is available.** Most panels have a built-in console, but if you want to connect your own [RCON client](/en/rcon-guide/) you need the host to give you the port and let you reach it.

**How updates work.** Mordhau patches break servers that are running an old build. Find out whether the host updates automatically or whether that is on you.

**How slots are billed.** Nearly all of these charge per slot. A 64 slot server costs roughly four times what a 16 slot one does, so be honest with yourself about how many people will actually show up.

## Or host it yourself

It is free, and it is not especially hard — the [dedicated server guide](/en/dedicated-server-guide/) walks through the whole thing. You need a machine that stays powered on and the ability to forward three ports. If you already have a VPS or a spare box, that is most of the work done.
