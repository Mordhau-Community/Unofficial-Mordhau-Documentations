# References

Where the information on this site comes from, and where to go when a page here does not cover what you need.

::: info
Everything below is maintained by someone else. If you find one of these dead or badly out of date, [tell us](https://github.com/Mordhau-Community/Unofficial-Mordhau-Documentations/issues) and we will drop it.
:::

## Official

- [Mordhau](https://mordhau.com) — the official site
- [Mordhau on Steam](https://store.steampowered.com/app/629760/MORDHAU/) — store page, and where patch notes are posted
- [Triternion on X](https://x.com/MordhauGame) — announcements usually land here first
- [Steam Community Hub](https://steamcommunity.com/app/629760) — discussions, guides and the workshop

## Running a server

- [LinuxGSM Mordhau config](https://github.com/GameServerManagers/Game-Server-Configs/tree/master/Mordhau) — a reference `Game.ini` with every default value in it. Useful for checking what a setting is supposed to look like
- [LinuxGSM](https://linuxgsm.com/servers/mhserver/) — management scripts for a Linux server, handles updates and restarts for you
- [cm2network/mordhau](https://github.com/CM2Walki/Mordhau) — Docker image, if you would rather run it in a container
- [SteamCMD documentation](https://developer.valvesoftware.com/wiki/SteamCMD) — Valve's own reference
- [mcrcon](https://github.com/Tiiffi/mcrcon) — the RCON client used in our [RCON guide](/en/rcon-guide/)
- [GPORTAL admin command list](https://www.g-portal.com/wiki/en/mordhau/) — admin and RCON commands with their syntax

## Modding

- [Mordhau Editor announcement](https://store.steampowered.com/news/app/629760/view/3147450638822972795) — the release post, December 2021
- [mod.io](https://mod.io) — the platform Mordhau uses to distribute mods
- [Unreal Engine documentation](https://dev.epicgames.com/documentation/en-us/unreal-engine) — the editor is a build of UE4, so most general UE material applies

## Citing sources

If you add technical detail to a page here, link where it came from. Not for formality's sake — it lets the next reader go deeper, and it lets whoever revisits the page in two years judge how likely it is to still be true.
