# More Resources

Everything below is external. We link out rather than restating it because these are all better maintained than a copy of them here would be.

## Markdown

- [CommonMark reference](https://commonmark.org/help/) — the whole syntax on one page, with a live editor
- [Markdown Guide](https://www.markdownguide.org/basic-syntax/) — the same ground, explained at more length
- [VitePress Markdown Extensions](https://vitepress.dev/guide/markdown) — the extras that only work on this site

## Git

- [Pro Git](https://git-scm.com/book/en/v2) — the official book, free online. Chapters 1 to 3 cover everything a contributor needs
- [Oh Shit, Git!?!](https://ohshitgit.com/) — how to undo the specific thing you just did wrong
- [Learn Git Branching](https://learngitbranching.js.org/) — an interactive visualiser, genuinely the fastest way to understand branches
- [git-scm reference](https://git-scm.com/docs) — every command and every flag

## GitHub

- [GitHub Quickstart](https://docs.github.com/en/get-started/quickstart)
- [Introduction to GitHub](https://github.com/skills/introduction-to-github) — a free hands-on course that ends with you having opened a real pull request
- [Connecting to GitHub with SSH](https://docs.github.com/en/authentication/connecting-to-github-with-ssh)

## VitePress

- [VitePress documentation](https://vitepress.dev)
- [Default theme configuration](https://vitepress.dev/reference/default-theme-config) — every option in `.vitepress/config.mts`
- [Internationalisation](https://vitepress.dev/guide/i18n) — how the language folders work

## Mordhau

- [Official Mordhau site](https://mordhau.com)
- [Mordhau on Steam](https://store.steampowered.com/app/629760/MORDHAU/)
- [Triternion on X](https://x.com/MordhauGame) — where patch announcements land first
