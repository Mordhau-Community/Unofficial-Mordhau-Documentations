# Références {#references}

D'où proviennent les informations présentes sur ce site et où aller lorsqu'une page ici ne couvre pas ce dont vous avez besoin.

Tout ce qui suit est géré par quelqu'un d'autre.Si vous en trouvez un mort ou gravement obsolète, indiquez [Dites-nous](https://github.com/Mordhau-Community/Unofficial-Mordhau-Documentations/issues) et nous le laisserons tomber.

##  {#official}

- [Mordhau](https://mordhau.com) — le site officiel
- [Mordhau sur Steam](https://store.steampowered.com/app/629760/MORDHAU/) — la page de la boutique et où les notes de mise à jour sont publiées
- [Triternion sur X](https://x.com/MordhauGame) — les annonces arrivent généralement ici en premier
- [Steam Centre communautaire](https://steamcommunity.com/app/629760) — discussions, guides et atelier

## Exécution d'un serveur {#running-a-server}

- [Configuration LinuxGSM Mordhau](https://github.com/GameServerManagers/Game-Server-Configs/tree/master/Mordhau) — une référence `Game.ini` contenant toutes les valeurs par défaut.Utile pour vérifier à quoi un paramètre est censé ressembler.
- [LinuxGSM](https://linuxgsm.com/servers/mhserver/) — scripts de gestion pour un serveur Linux, gère les mises à jour et les redémarrages pour vous
- [cm2réseau/mordhau](https://github.com/CM2Walki/Mordhau) — Image Docker, si vous préférez l'exécuter dans un conteneur
- [SteamCMD documentation](https://developer.valvesoftware.com/wiki/SteamCMD) — Référence propre à Valve
- [mcrcon](https://github.com/Tiiffi/mcrcon) — le client RCON utilisé dans notre [Guide RCON](/fr/rcon-guide/)
- [Liste des commandes d'administration GPORTAL](https://www.g-portal.com/wiki/en/mordhau/) — commandes admin et RCON avec leur syntaxe

## Modding {#modding}

- [MORDHAU Editor sur l'Epic Games Store](https://store.epicgames.com/p/mordhau--editor) — l'éditeur lui-même, gratuit, et le seul endroit où il est distribué
- [Mordhau Annonce de la rédaction](https://store.steampowered.com/news/app/629760/view/3147450638822972795) — la publication de décembre 2021
- [mod.io](https://mod.io) — la plateforme utilisée par Mordhau pour distribuer les mods
- [Unreal Engine documentation](https://dev.epicgames.com/documentation/en-us/unreal-engine) — l'éditeur est une versionde UE4, donc le matériel UE le plus général s'applique
