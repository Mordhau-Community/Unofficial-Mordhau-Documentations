# Méthodes de contribution {#contribution-methods}

Il existe plusieurs façons d'aider ici, et toutes n'impliquent pas le clonage d'un référentiel.Choisissez celui qui correspond au temps que vous souhaitez passer.

## 1. Ouvrir un ticket {#1-open-an-issue}

L'option qui demande le moins d'effort, et honnêtement la plus utile lorsque vous avez repéré quelque chose de mal.Vous avez trouvé une commande qui ne fonctionne plus ?Un lien mort ?Une page qui se contredit ?Ouvrez un [Numéro](https://github.com/Mordhau-Community/Unofficial-Mordhau-Documentations/issues) et décrivez-le.

Un bon numéro indique sur quelle page vous étiez, ce à quoi vous vous attendiez et ce qui s'est réellement passé.Vous n'êtes pas obligé de connaître le correctif.

## 2. Modifier une page à partir du navigateur {#2-edit-a-page-from-the-browser}

Chaque page de ce site comporte un lien **Modifier cette page** en bas.En cliquant dessus, vous ouvrez ce fichier exact dans l'éditeur de GitHub.Effectuez votre modification, écrivez une courte note la décrivant, et GitHub créera le référentiel et ouvrira la demande d'extraction pour vous.

C'est le bon choix en cas de fautes de frappe, d'un lien rompu, d'une phrase mal lue ou d'un petit ajout.Pas de terminal, pas d'installation, rien à configurer.

## 3. Travaillez localement {#3-work-locally}

Une fois que vous modifiez plus d'un fichier - ou ajoutez une page ou touchez la barre latérale - cela vaut la peine de configurer le projet sur votre ordinateur afin que vous puissiez voir le résultat avant de l'envoyer.Le [présentation](/fr/contributing/) parcourt le clone et le serveur de développement.

Travaillez localement lorsque vous êtes :

- ajouter une toute nouvelle page
- restructurer une section
- modifier la navigation dans `.vitepress/config.mts`
- ajouter des images

## 4. Traduire {#4-translate}

Le site fonctionne déjà en anglais, arabe, français, japonais, russe et chinois, mais la plupart des dossiers traduits sont loin derrière ceux en anglais.Remplir une page dans une langue que vous parlez réellement est l’une des choses les plus précieuses que vous puissiez faire ici.

Les traductions sont disponibles dans `docs/<language>/`, reflétant la structure anglaise.Copiez le fichier anglais dans le chemin correspondant dans votre dossier de langue et traduisez le corps.Laissez les clés de premier plan tranquilles : traduisez uniquement les valeurs.

::: warning
Veuillez ne pas soumettre de pages traduites automatiquement.Une page brouillon écrite par quelqu'un qui parle la langue bat une page fluide qui contient des termes techniques erronés, et nous n'avons aucun moyen de réviser une langue qu'aucun de nous ne lit.
:::

## 5. Partagez ce que vous savez déjà {#5-share-what-you-already-know}

De nombreuses connaissances sur Mordhau se trouvent dans les fils de discussion Discord et les anciens messages du forum.Si vous utilisez un serveur depuis des années ou si vous avez compris quelque chose sur le SDK qui n'est écrit nulle part, vous n'avez pas besoin de le transformer vous-même en une page soignée.Déposez-le dans le [Discord](https://discord.gg/zuX58yRV84) ou collez-le dans un problème et quelqu'un vous aidera à le façonner.

La moitié de l'intérêt de ce projet est de collecter des objets avant que les personnes qui les connaissent ne partent.
