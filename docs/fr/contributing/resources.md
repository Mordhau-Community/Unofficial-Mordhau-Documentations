# Plus de ressources {#more-resources}

Tout ce qui suit est externe.Nous établissons des liens plutôt que de les reformuler, car ils sont tous mieux conservés qu'une copie d'entre eux ici ne le serait.

## Markdown {#markdown}

- [Référence CommonMark](https://commonmark.org/help/) — toute la syntaxe sur une page, avec un éditeur en direct
- [Markdown Guide](https://www.markdownguide.org/basic-syntax/) — le même principe, expliqué plus en détail
- [VitePress Markdown Prorogations](https://vitepress.dev/guide/markdown) — les extras qui ne fonctionnent que sur ce site

## Git {#git}

- [Pro Git](https://git-scm.com/book/en/v2) — le livre officiel, gratuit en ligne.Les chapitres 1 à 3 couvrent tout ce dont un contributeur a besoin.
- [Oh merde, Git !?!](https://ohshitgit.com/) — comment annuler une erreur spécifique que vous venez de faire
- [Apprendre la branche Git](https://learngitbranching.js.org/) — un visualiseur interactif, véritablement le moyen le plus rapide de comprendre les branches
- [référence git-scm](https://git-scm.com/docs) — chaque commande et chaque indicateur

## GitHub {#github}

- [GitHub Quickstart](https://docs.github.com/en/get-started/quickstart)
- [Introduction à GitHub](https://github.com/skills/introduction-to-github) — un cours pratique gratuit qui se termine par l'ouverture d'une véritable pull request
- [Connexion à GitHub avec SSH](https://docs.github.com/en/authentication/connecting-to-github-with-ssh)

## VitePress {#vitepress}

- [VitePress documentation](https://vitepress.dev)
- [Configuration par défaut du thème](https://vitepress.dev/reference/default-theme-config) — toutes les optionsdans `.vitepress/config.mts`
- [Internationalisation](https://vitepress.dev/guide/i18n) — fonctionnement des dossiers de langue

## Mordhau {#mordhau}

- [Site officiel de Mordhau](https://mordhau.com)
- [Mordhau sur Steam](https://store.steampowered.com/app/629760/MORDHAU/)
- [Triternion sur X](https://x.com/MordhauGame) — où les annonces de correctifs arrivent en premier
