# À propos de nous {#about-us}

Mordhau Guides est un projet de documentation non officiel pour le jeu Mordhau,
écrit et maintenu par des contributeurs bénévoles.

La plupart de ce qui est nécessaire pour exécuter un serveur dédié, utiliser RCON ou travailler avec le SDK
existe depuis des années, dispersé dans les fils de discussion Discord, les messages du forum et les notes privées
.Ce matériel se perd facilement : un fil de discussion défile hors de portée, un propriétaire de serveur
arrête de jouer.Le projet le rassemble en un seul endroit, dans un ordre fixe
, et le maintient à jour au fur et à mesure que le jeu est corrigé.

Le projet est indépendant.Il n'est pas affilié à Triternion ni approuvé par
, et chaque page est écrite par les joueurs plutôt que par les développeurs.

Les contributions sont ouvertes à tous, et la plupart de ce qui est utile est petit : une correction
, une étape manquante, une page traduite dans une autre langue.
[Comment contribuer](/fr/contributing/) décrit le processus.
