## Официальный {#official}

- [Mordhau](https://mordhau.com) — официальный сайт
- [Mordhau для Steam](https://store.steampowered.com/app/629760/MORDHAU/) — страница магазина, где публикуются примечания к патчу.
- [Triternion для X](https://x.com/MordhauGame) — объявления обычно попадают сюда первыми.
- [Steam Общественный центр](https://steamcommunity.com/app/629760) — обсуждения, гайды и мастер-класс

## Запуск сервера {#running-a-server}

- [Конфигурация LinuxGSM Mordhau](https://github.com/GameServerManagers/Game-Server-Configs/tree/master/Mordhau) — ссылка `Game.ini` со всеми значениями по умолчанию.Полезно для проверки того, как должна выглядеть настройка.
- [LinuxGSM](https://linuxgsm.com/servers/mhserver/) — сценарии управления для сервера Linux, обрабатывающие обновления и перезапуски за вас.
- [cm2network/mordhau](https://github.com/CM2Walki/Mordhau) — образ Docker, если вы предпочитаете запускать его в контейнере.
- [Документация SteamCMD](https://developer.valvesoftware.com/wiki/SteamCMD) — собственная ссылка Valve.
- [макрон](https://github.com/Tiiffi/mcrcon) — клиент RCON, используемый в нашем [Руководство RCON](/ru/rcon-guide/).
- [Список команд администратора GPORTAL](https://www.g-portal.com/wiki/en/mordhau/) — команды администратора и RCON с их синтаксисом.

## Моддинг {#modding}

- [Mordhau Объявление редактора](https://store.steampowered.com/news/app/629760/view/3147450638822972795) — релизный пост, декабрь 2021 г.
- [mod.io](https://mod.io) — платформа, которую Mordhau использует для распространения модов.
- [Документация Unreal Engine](https://dev.epicgames.com/documentation/en-us/unreal-engine) — редактор представляет собой сборку UE4, поэтому применимы самые общие материалы UE.
