# Что такое Git? {#what-is-git}

Git сохраняет историю папки.Каждый раз, когда вы сохраняете контрольную точку — *коммит* — она записывает, что изменилось, когда и кто это сделал.Вы можете вернуться к любой предыдущей контрольной точке, и два человека смогут работать с одной и той же папкой одновременно, не перезаписывая друг друга.

Это не имеет ничего общего с Mordhau.Это универсальный инструмент, используемый почти для каждого существующего программного проекта, и мы используем его здесь, потому что эти документы представляют собой папку с текстовыми файлами, которые редактируют многие люди.

::: info
Git и GitHub — это две разные вещи.Git — это программа на вашем компьютере.GitHub — это веб-сайт, на котором в Интернете хранятся репозитории Git.Вы можете использовать Git без GitHub.См. [Что такое GitHub?](/ru/contributing/github).
:::

## Слова {#the-words}

Вы будете постоянно сталкиваться с этим словарем, поэтому стоит разобраться заранее.

**Репозиторий** (или репо) — папка проекта плюс вся его история.Этот сайт представляет собой один репозиторий.

**Клонировать** — скачать копию репозитория, истории и всего остального.

**Commit** — сохраненная контрольная точка с сообщением, описывающим, что вы изменили.

**Филиал** — отдельное направление работы.Вы вносите изменения в свою собственную ветку, чтобы основная продолжала работать, пока вы находитесь на полпути.

**Push** — отправьте свои коммиты со своего компьютера на адрес GitHub.

**Pull** — отменить фиксации, сделанные другими людьми.

**Объединить** — объединить одну ветку в другую.

## Пять команд, которые вам действительно нужны {#the-five-commands-you-actually-need}

Чтобы внести свой вклад, не обязательно должным образом изучать Git.Вот весь цикл:

```bash
# 1. Get the project onto your machine, once
git clone https://github.com/Mordhau-Community/Unofficial-Mordhau-Documentations.git
cd Unofficial-Mordhau-Documentations

# 2. Start a branch for what you are about to do
git checkout -b fix-rcon-ports

# 3. Edit files in your editor, then check what Git noticed
git status

# 4. Save a checkpoint
git add .
git commit -m "Correct the default RCON port"

# 5. Send it to GitHub
git push origin fix-rcon-ports
```

Затем вы открываете запрос на вытягивание на веб-сайте, который описан в [Что такое GitHub?](/ru/contributing/github).

## Две привычки, которые стоит иметь {#two-habits-worth-having}

**Писать сообщения о коммитах, которые что-то значат.** «Исправлено» — шесть месяцев спустя никто ничего не скажет.«Исправить порт маяка в руководстве по серверу» помогает.

**Создавайте новую ветку для каждой задачи, над которой вы работаете.** Это стоит одной команды и означает, что вы можете иметь два несвязанных исправления в работе, не перепутывая их.

## Сохранение актуальности вашей копии {#keeping-your-copy-current}

Если вы клонировали некоторое время назад, с тех пор другие люди что-то изменили.Перед началом новой работы:

```bash
git checkout main
git pull
git checkout -b my-new-branch
```

## Если вы застряли {#if-you-get-stuck}

Сообщения об ошибках Git, как известно, бесполезны.Ничего из того, что вы делаете локально, невозможно восстановить, пока вы не удалили папку, поэтому не паникуйте.

- — [Официальная книга Git](https://git-scm.com/book/en/v2) — бесплатно, а в первых двух главах все вышеперечисленное рассматривается более подробно
- — [Чёрт, Гит!!](https://ohshitgit.com/) — короткие ответы на вопрос «Я сделал что-то не так, как это отменить»

Или спросите в [Discord](https://discord.gg/zuX58yRV84).Кто-то столкнулся с той же ошибкой.
