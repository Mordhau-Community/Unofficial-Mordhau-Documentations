# Что такое GitHub? {#what-is-github}

GitHub — это веб-сайт, на котором размещены репозитории Git.Он хранит проект в Интернете, поэтому все работают с одной и той же копией, и добавляет вещи, о которых сам Git не имеет мнения: отслеживание проблем, проверку кода и запросы на включение.

Источник этого сайта находится по адресу [Mordhau-Сообщество/Неофициальный Mordhau-Документы](https://github.com/Mordhau-Community/Unofficial-Mordhau-Documentations).Каждая страница, которую вы здесь читаете, представляет собой файл Markdown в этом репозитории.

Если разница между Git и GitHub еще не ясна, сначала прочитайте [Что такое Гит?](/ru/contributing/git).

## Получение аккаунта {#getting-an-account}

Бесплатно.Зарегистрируйтесь по адресу [github.com](https://github.com), указав адрес электронной почты и имя пользователя — имя пользователя является общедоступным и отображается во всем, что вы публикуете, поэтому выберите то, под которым вы будете рады, что вас знают.

Включите двухфакторную аутентификацию прямо в настройках.GitHub в любом случае требует этого для участников.

## Форк, ветвь, запрос на включение {#fork-branch-pull-request}

Это рабочий процесс, на котором работает весь сайт, и он везде один и тот же на GitHub.

### 1. Форк {#1-fork}

У вас нет разрешения на отправку напрямую в основной репозиторий, и это сделано намеренно.Нажав **Разветвить**, вы получите собственную полную копию под своей учетной записью, с которой вы сможете делать все, что захотите.

### 2. Внесите изменения {#2-make-your-changes}

Либо в браузере, либо клонировав свою вилку и работая локально.Поместите их на ветку, а не прямо на `main`.

### 3. Откройте запрос на включение {#3-open-a-pull-request}

Запрос на включение — это запрос на внесение ваших изменений в исходный репозиторий.GitHubпоказывает, что именно вы изменили, строка за строкой, и дает каждому возможность обсудить это, прежде чем что-либо будет объединено.

Напишите описание, в котором будет указано, что вы изменили и почему.Если это устраняет проблему, укажите номер проблемы — запись `Fixes #42` автоматически закрывает эту проблему после объединения запроса на включение.

### 4. Ответить на отзыв {#4-respond-to-review}

Кто-нибудь прочитает.Они могут попросить внести изменения.Отправьте еще один коммит в ту же ветку, и запрос на включение обновится сам по себе — вы не открываете новый.

После того, как он будет одобрен и объединен, Netlify перестраивает сайт, и ваши изменения вступают в силу в течение нескольких минут.

## Редактирование без всего этого {#editing-without-any-of-that}

За опечатку ничего форковать не надо.На каждой странице внизу есть ссылка **Изменить эту страницу**.Он открывает редактор GitHub именно для этого файла, и когда вы сохраняете его, GitHub молча выполняет за вас форк и запрос на включение.

## Проблемы {#issues}

[Отслеживание проблем](https://github.com/Mordhau-Community/Unofficial-Mordhau-Documentations/issues) — это место, где сообщаются о проблемах и планируются работы.Откройте его, если вы нашли что-то не так и не собираетесь это исправлять самостоятельно, если хотите предложить страницу, которой не существует, или если вы не уверены, стоит ли реализовывать идею, прежде чем тратить на нее время.

Сначала выполните поиск существующих проблем.Возможно, кто-то уже поднимал эту тему.

## Просмотр репозитория {#watching-the-repository}

Кнопка **Смотреть** в верхней части репозитория будет сообщать вам по электронной почте, когда что-то произойдет.**Пользовательский → Проблемы** обычно является подходящим вариантом, если вы хотите помочь, но не хотите получать уведомления о каждом коммите.

## Узнать больше {#learning-more}

GitHub [Быстрый старт](https://docs.github.com/en/get-started/quickstart) действительно хорош и занимает около пятнадцати минут.В GitHub Skills также есть бесплатный курс [Введение в GitHub](https://github.com/skills/introduction-to-github), который поможет вам открыть настоящий запрос на включение.
