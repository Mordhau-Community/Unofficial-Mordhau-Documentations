# Дополнительные ресурсы {#more-resources}

Все, что ниже, является внешним.Мы даем ссылку, а не повторяем это, потому что все они поддерживаются лучше, чем их копии здесь.

## Markdown {#markdown}

- [Ссылка на CommonMark](https://commonmark.org/help/) — весь синтаксис на одной странице с живым редактором
- [Markdown Руководство](https://www.markdownguide.org/basic-syntax/) — то же самое заземление, объяснено более подробно.
- [VitePress Markdown Расширения](https://vitepress.dev/guide/markdown) — дополнения, которые работают только на этом сайте

## Гит {#git}

- [Pro Git](https://git-scm.com/book/en/v2) — официальная книга, бесплатно онлайн.Главы 1–3 охватывают все, что нужно участнику.
- [Чёрт, Гит!!](https://ohshitgit.com/) — как отменить конкретную вещь, которую вы только что сделали неправильно
- [Учить Git Branching](https://learngitbranching.js.org/) — интерактивный визуализатор, действительно самый быстрый способ понять ветки.
- [git-scm ссылка](https://git-scm.com/docs) — каждая команда и каждый флаг

## GitHub {#github}

- [GitHub Quickstart](https://docs.github.com/en/get-started/quickstart)
- [Введение в GitHub](https://github.com/skills/introduction-to-github) — бесплатный практический курс, который заканчивается тем, что вы открываете настоящий запрос на включение
- [Подключение к GitHub с помощью SSH](https://docs.github.com/en/authentication/connecting-to-github-with-ssh)

## VitePress {#vitepress}

- [Документация VitePress](https://vitepress.dev)
- [Конфигурация темы по умолчанию](https://vitepress.dev/reference/default-theme-config) — все опции в `.vitepress/config.mts`
- [Интернационализация](https://vitepress.dev/guide/i18n) — как работают языковые папки

- [Triternion для X](https://x.com/MordhauGame) — где в первую очередь появляются анонсы обновлений
